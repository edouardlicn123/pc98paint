# 05 脸部与五官设计（依据 refs/proportions/shinchou_01–24）

样本：24 张 PC-98 galgame 立绘/半身，全部为同代（1990s 后期）商业作品。
本文只讨论**五官与发型**；身材比例见 `docs/03`，用色见 `docs/04`。

---

## 1 五官的像素画法（通用层）

### 1.1 眼睛：只有三种基本型

| 型 | 形状 | 像素特征 | 用于 |
|---|---|---|---|
| **圆眼** | 高≈宽，正圆或略椭圆 | 虹膜占满 2/3，**上下各一道高光**，下眼线浅或不画 | 幼女、元气少女 |
| **杏眼** | 宽>高，外眼角上挑 | 上眼线 2px 加粗，虹膜 1/2，单高光在左上 | 标准女性、职业女性 |
| **细眼** | 宽≈高的 2 倍，狭长 | 上眼线 1–2px，虹膜只留一条竖缝，常无高光 | 成年男性、冷感角色 |

补充规律：
- **眼睛高度随年龄递减**：萝莉（02、24）眼睛高≈脸高 1/4；高中生≈1/5；成年男性≈1/7。
- 高光位置固定：圆眼两道（左上 + 右下），杏眼一道（左上），细眼零道。
- 睫毛线只在**女性**画，且只画上眼线外侧 1/3；男性画整条上眼线会变女相。

#### 1.1.1 参考图定稿：竖长杏眼（2026-11-22，`refs/faces/eye_ref_01.png`）

参考图是 3/4 侧脸近景（119×121 原像素），眼型为**竖长杏眼**：比 §1.1 的通用杏眼更高、更圆一点。以下是把它的画法翻译成 PC-98 像素规则的定稿。

**特征拆解**

| 部位 | 参考图表现 | PC-98 译法 |
|---|---|---|
| 整体 | 眼高 ≈ 1.15×眼宽，竖长 | 眼宽 = 眼高 × 0.85 |
| 上眼线 | 最粗 2–3px，外眼角加粗上挑 | `black` 2–3px，外 1/3 再加 1px |
| 下眼线 | 只画外侧一半，暖棕不是黑 | `brown` / `red_dark` 1px，内半段省略 |
| 虹膜 | 上 1/3 深蓝紫，下 2/3 酒红，硬边分界 | `navy_mid`/`blue` + `red_dark`/`red` 两段 |
| 瞳孔 | 近黑，位置略偏上 | `black`，占虹膜高 35% |
| 高光 | 10 点钟大弧 + 7 点钟小点 | `white`，大高光 ≈22% 虹膜高，小点 1–2px |
| 眼白 | 上缘有 1px 阴影 | `lavender` 1px（备选 `gray_green_light`） |
| 睫毛 | 外角 2 根短刺 | `black` 1–2px，**只给女性** |

**层序（从下到上）**

1. 眼白 `white`
2. 上眼睑阴影 `lavender` 1px（只在眼白顶部）
3. 虹膜底色 `red_dark`（下半 2/3），上 1/3 覆 `navy_mid`
4. 瞳孔 `black`
5. 下眼线 `brown` 1px（外侧 1/2）
6. 上眼线 `black` 2–3px，外角加粗
7. 高光 `white`

> **高光是纯白，不是材质暗档**：`white (255,255,255)` 只给高光与眼白，**禁止**被归入白衣的灰绿暗档，也禁止被染成肤色。同一角色**两眼必须同时有高光**，同钟点、同尺寸、同色；少一只眼、或者两只眼一白一灰/一肉色，都算不合格。管线里小面积白色（<200px）不参与材质分带，眼内被虹膜/眼线包围的小亮块强制归白。

> 双色虹膜只用**硬边两段**；特写档可在交界加 1px 棋盘交错（两色 Lab ΔE ≤10），半身/全身不加。

**尺寸换算（头高 H）**

| 量 | 公式 | H=60（三视图） | H=120（半身） | H=360（特写） |
|---|---|---|---|---|
| 眼高 | 0.16H | 10 | 19 | 58 |
| 眼宽 | 0.14H | 8 | 17 | 49 |
| 虹膜高 | 0.11H | 7 | 13 | 40 |
| 上眼线 | max(1, 0.10×眼高) | 1 | 2 | 4 |
| 高光 | max(1, 0.22×虹膜高) | 1–2 | 3 | 9 |

**三视图的三个视角**

| 视角 | 画法 |
|---|---|
| 正面 | 双眼等大；内眼角间距 = 1 个眼宽；两眼高光同在左上 |
| 四分之三 | 远端眼宽 ×0.72，虹膜向视线方向偏 1–2px；近端眼完整；鼻梁线落在远端眼内眼角内侧 |
| 侧面 | 只画近端一眼，轮廓压成楔形；虹膜只露前缘 1/3（一条 `red_dark`），高光缩为 1px；上眼线延长到太阳穴；不画下眼线内半段 |
| 背面 | 不画 |

**三档可用性**

| 要素 | 特写 | 半身 | 全身 / 三视图 |
|---|---|---|---|
| 双色虹膜 | ✅ 带 1px 交错 | ✅ 硬边 | ⚠️ 退化为 `red_dark` 单色 |
| 双高光 | ✅ | ✅ 只留大高光 | ❌ 只留 1px 点 |
| 下眼线 | ✅ 外侧 1/2 | ✅ 1px | ❌ |
| 睫毛 | ✅ 2 根 | ✅ 1 根 | ❌ |
| 上眼睑阴影 | ✅ | ✅ | ❌ |

**禁止**：圆瞳孔、纯黑虹膜、渐变、虹膜 4 档以上明暗、高光碎点、高光面积超过虹膜 1/3、左右眼高光方向不一致（光源固定左上 45°）、**高光被染成肤色或灰绿**、**只有一只眼有高光**。

#### 1.1.2 参考图 02：圆润酒红眼（2026-11-22，`refs/faces/eye_ref_02.png`）

129×85 的双眼近景（近正面）。和 01 同属大眼，但更圆、更暖、更幼。

| 部位 | 参考图表现 | PC-98 译法 |
|---|---|---|
| 整体 | 眼高 ≈ 1.1×眼宽，圆润，外眼角略上挑 | 眼宽 = 眼高 × 0.90 |
| 上眼线 | 3–4px 深棕黑，外角更粗 | `black` 3px + 内侧 `brown` 1px 过渡 |
| 双眼皮 | 上眼线上方 1–2px 一条细线 | `brown` 1px，只特写/半身画 |
| 虹膜 | 主体酒红，上缘近黑，下缘透光亮红 | `red_dark` 主体 + 上缘 `black`/`brown` + 下缘 `red` 1–2px |
| 瞳孔 | 大，占虹膜 40–45%，略偏上 | `black` |
| 高光 | 左上大弧（青白）+ 4 点钟小白点 | `white`；大高光 25% 虹膜高，小点 1px |
| 眼白 | 上缘 1px 冷阴影 | `lavender` 1px |
| 下眼线 | 细，暖棕，外侧 2/3 | `brown` 1px |
| 睫毛 | 外角 1–2 根短刺 | `black` 1px，只女性 |

**层序**：眼白 → 上眼睑阴影 → 虹膜 `red_dark` → 上缘 `brown`/`black` 加深 → 下缘 `red` 透光 → 瞳孔 `black` → 下眼线 `brown` → 上眼线 `black` → 双眼皮线 → 高光。

**尺寸**：与 §1.1.1 同一套公式（眼高 0.16H、虹膜 0.11H、上眼线 max(1, 0.10×眼高)），只把眼宽系数改为 0.90。

**三视图视角**：正面/四分之三/侧面规则同 §1.1.1；差别是**下缘透光 `red`**——正面画成虹膜底部的 1–2px 弧，四分之三只画近端眼，侧面不画。

**三档可用性**：特写保留双眼皮线与下缘透光；半身保留下缘 `red` 1px、删双眼皮线；全身/三视图退化为 `red_dark` 单色 + 1px 高光。

#### 1.1.3 两套参考怎么选

| 指标 | 01 竖长杏眼 | 02 圆润酒红眼 |
|---|---|---|
| 眼型 | 更高更窄（宽=高×0.85） | 更圆更宽（宽=高×0.90） |
| 虹膜 | 蓝紫 + 酒红双色 | 酒红单色 + 下缘透光 |
| 高光 | 10 点大弧 + 7 点小点 | 10 点大弧 + 4 点小白点 |
| 附加线 | 无 | 双眼皮线 |
| 读感 | 清冷、文静、稍成熟 | 温柔、亲和、幼 |
| 适用 | 文静型少女 / 成年女性 | 元气 / 妹妹 / 治愈系 |

两套共用同一套层序、尺寸公式与三视图视角规则，**只换虹膜配色、高光点和眼宽系数**；同一角色只能选一套，不要混用。

### 1.2 眉毛：决定气质强度

| 型 | 画法 | 读感 | 样本 |
|---|---|---|---|
| 粗斜眉 | 3–4px 粗、外高内低 | 强、运动、攻击性 | 03、22、23 |
| 粗平眉 | 3px 水平 | 憨、老实、好脾气 | 09、23 |
| 细弯眉 | 1px，弓形 | 柔和、女性 | 04、07、14、20 |
| 细平眉 | 1px 水平 | 中性、冷淡 | 11、15、16 |
| 下垂眉 | 外低内高 | 软弱、内向 | 05、24 |

**眉毛粗细是性别第一开关**：同一张脸，眉毛从 1px 加到 3px 并压平，就从女性变成男性。

### 1.3 鼻子：全样本只有 3 种画法

| 型 | 画法 | 用于 |
|---|---|---|
| 点 | 1px 暗色点 | 幼女、少女（02、18、21、24） |
| 短竖 | 2–3px 竖线 | 少女、青年（03、07、11、17） |
| L 形 | 竖线 + 向右下的 2px 鼻梁阴影 | 成年、男性（09、19、22） |

鼻子**不承担性格**，只承担年龄。同一作品里所有角色共用同一种鼻子画法。

### 1.4 嘴巴：5 种

| 型 | 画法 | 读感 |
|---|---|---|
| 一线 | 3–5px 水平黑线 | 冷静、无表情（07、15） |
| 短线 | 2px | 小嘴、可爱（02、17、24） |
| 上弯 | 两端上翘 1px | 亲和、微笑（06、08、11、16） |
| 下弯 | 两端下压 1px | 不悦、紧张（01） |
| 张口 | 黑色块 + 上齿白线 | 热血、粗犷（09、22） |

唇色：女性成年角色在唇上铺 1–2px 红色（10、14、20）；少女与男性不铺，只留黑线。
**唇色是成年女性的第二开关**（第一开关是杏眼 + 上眼线）。

### 1.5 眼镜：性格开关（7/24 = 29% 的角色戴）

| 型 | 画法 | 读感 | 样本 |
|---|---|---|---|
| 圆细框 | 1px 圆环 + 鼻梁横线 | 文静、书呆 | 01、19 |
| 方厚框 | 4–5px 黑色矩形 | 宅、保守、内向 | 05、23 |
| 方细框 | 1px 矩形 | 优等生、精英 | 12、16 |
| 墨镜 | 整块黑 + 1px 白色反光斜线 | 不良、隐藏情绪、痞 | 13 |

眼镜框会**吃掉眼睛的 1/3 面积**，所以戴眼镜的角色眼睛必须画大一号，否则全身档会看不见眼。

### 1.6 发型：三个轴 + 发色

| 轴 | 取值 |
|---|---|
| **长度** | 短（耳上）／鲍伯（下颌）／中长（肩）／长（过腰） |
| **前发** | 齐刘海／斜分／中分露额／遮单眼／全梳上（背头）／无前发（刺发） |
| **束发** | 无／双马尾／单马尾／盘发／头带·头巾 |
| **发色** | 自然（黑、棕、金、灰白）／非自然（绿、粉、洋红、青绿） |

#### 1.6.1 长度先由年龄与性别决定

- **男性 24 人全部短发**（无一人过耳）：这是最硬的约束，男性发型只在前发和质地（刺发/背头/乱卷/锅盖）上变化。
- 女性按年龄分档：幼女短或鲍伯（02、24）→ 少女短到中长（01、07、17、18、21）→ 成年中长到长（04、08、10、14、15、20）。
- 唯一的成年短发是 15（银灰 + 遮单眼），用"冷感"换掉了长度带来的成熟度。

#### 1.6.2 前发是情绪开关

| 前发 | 读感 | 样本 |
|---|---|---|
| 齐刘海 | 乖巧、幼 | 24 |
| 斜分 | 标准、中性 | 01、07、17、21 |
| 中分露额 | 成熟、自信 | 20 |
| 遮单眼 | 冷、神秘、不好接近 | 15 |
| 全梳上（背头） | 社会、强硬、老练 | 09、19、22 |
| 无前发（刺发） | 运动、不良 | 03、18 |

#### 1.6.3 束发 = 幼态或职业度

- **双马尾（02）** 是最高幼态，配蝴蝶结；全样本只有 1 例，越少越有效。
- **盘发（10）** 是最高成熟度，配红唇与大蝴蝶结，读作"人妻/职业女性"。
- **头带/头巾（03、13、17）** 读作运动或不良，是短发角色唯一能加的"外凸轮廓"。
- 单马尾 0 例——这个年代的发型库不追求齐全，够用就停。

#### 1.6.4 发色只承担区分度

- 自然色 **17/24**（黑、棕、金、灰白）；非自然色 **7/24**（绿 01/21、粉 02/13、洋红 11/18、青绿 12）。
- **非自然色全部是学生**；社会人、成年、教师一律自然色。发色是"还在校园里"的隐性标记。
- 同一色可给相反性格：绿发 01 文静、21 元气。**不要用发色写性格**。

#### 1.6.5 卷度是成年女性的专属

- 卷发只出现在成年女性（04 金长卷、08 棕红中长卷、20 金长蓬发）和宅男（05 乱卷）。
- 学生与男性一律直发或刺发。卷 = 成熟或不修边幅，二者都靠轮廓读出来。

#### 1.6.6 像素画法

| 部件 | 画法 |
|---|---|
| 发块 | 大块纯色填充，发根 / 颈后 / 耳下各 1 块同色相暗部 |
| 亮带 | 头顶弧 + 外缘各 1 条，**连续一段**，不逐根 |
| 刘海齿 | 三角或梯形，齿距 特写 6–8px / 半身 4–6px / 全身 2–3px |
| 发梢 | 2px 步进锯齿，不用渐变收尾 |
| 发饰 | 1–2 个色块 + 1px 黑边，面积不超过脸宽的 1/3 |

**禁止**：逐根发丝线、渐变、4 档以上明暗、把高光画成碎点。

#### 1.6.7 三档可用性

| 发型要素 | 特写 | 半身 | 全身 |
|---|---|---|---|
| 长度 | ✅ | ✅ | ✅ 剪影可读 |
| 前发 | ✅ | ✅ | ❌ |
| 束发/发饰 | ✅ | ✅ | ⚠️ 只留外凸轮廓（双马尾、头带） |
| 发色 | ✅ | ✅ | ✅ 最稳 |
| 卷度 | ✅ | ⚠️ | ❌ |

结论：**全身档的发型只靠「长度 + 束发外轮廓 + 发色」三项**。发型是全身体系里比五官更可靠的识别点——五官全部失效，发型还能读出"是谁"。

## 3 设计公式：性格 → 五官

这 24 张背后是一套**可复用的组合表**，不是每个角色独立设计：

```
性格 = 眼睛型 × 眉毛型 × 嘴型 × 一个记忆点
年龄 = 眼高比 + 鼻子型 + 唇色
性别 = 眉粗 + 下颌线 + 上眼线浓淡
```

### 3.1 四条互不干扰的轴

| 轴 | 只改这一项 | 效果 |
|---|---|---|
| 年龄 | 眼睛占总脸比例（1/4 → 1/7）、鼻子（点→短竖→L）、唇色 | 幼 ↔ 成熟 |
| 性别 | 眉粗（1px→3px）、下颌（圆→方）、上眼线 | 女 ↔ 男 |
| 强度 | 眉毛角度（上挑/平/下垂）、嘴（上弯/一线/下弯） | 强势 ↔ 软弱 |
| 记忆点 | 眼镜、发色、束发、头巾、胡须 | 区分度 |

**关键：四个轴各自只动自己的参数**。03 和 16 同为男高中生，区别只在"粗斜眉+细眼+头带"vs"细平眉+细眼+方细框+立领"，年龄性别参数完全一致。

### 3.2 记忆点只能有一个主、一个副

- 01：主=圆眼镜，副=粉蝴蝶结
- 13：主=墨镜，副=头巾
- 23：主=厚眼镜，副=锅盖头

超过两个记忆点会糊成一团，玩家记不住。

### 3.3 眼镜是"反差"工具

7 个戴眼镜的角色里，5 个是"表里不一"：01（文静但嘴下弯）、05（宅但凶）、12（斯文但散漫）、23（憨但精明）。**给角色加眼镜，等于给他加一层"看起来怎样 / 其实怎样"的落差**。

## 4 落到像素管线的规则

按本项目三档的实际尺寸（脸宽：特写 127px / 半身 68px / 全身 31px）：

| 特征 | 特写 | 半身 | 全身 |
|---|---|---|---|
| 眼型（圆/杏/细） | ✅ 可辨 | ✅ 可辨 | ⚠️ 只剩宽高比 |
| 高光 | ✅ 2–3px | ⚠️ 1px | ❌ 丢失 |
| 眉型 | ✅ | ✅ | ❌ 只剩粗细 |
| 鼻型 | ✅ | ⚠️ 点与短竖不可分 | ❌ |
| 嘴型 | ✅ | ✅ 1–3px | ❌ 一线 |
| 眼镜 | ✅ | ✅ 轮廓可辨 | ⚠️ 只能靠"框缺口" |
| 唇色 | ✅ | ⚠️ 1px | ❌ |
| 发色/束发 | ✅ | ✅ | ✅ 最稳 |

结论：
1. **角色的辨识特征必须放在半身档以上才生效**。全身档只能读出发色和束发，所以全身档的角色必须靠**发型剪影**区分，不能靠五官。
2. 特写档才画得起"双高光 + 睫毛线 + 唇色"这一套；半身档要主动简化成单高光、无睫毛。
3. 眼镜在所有档位都优先保留轮廓——它是数据量最小、辨识度最高的记忆点（1px 圆环即可）。
