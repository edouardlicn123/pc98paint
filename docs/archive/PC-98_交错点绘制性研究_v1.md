# 交错点作为笔法

## ——PC-98 像素图像的过渡语法，与二次文献的“滤镜化”误读

**摘要**　本文源于一次失败的作品实践：作者以“高分辨率生成 + 全局 Bayer 抖动 + 减色”的方式制作 PC-98 风格立绘与背景，结果在观感上接近“加了噪点的插画”，而非 1990 年代日本 PC-9801 视觉小说的画面。本文据此重新梳理相关文献，将既有资料分为“过程性证据”与“表征性描述”两类，并以位置（where）、方向（direction）、密度（density）三要素为判据，指出后一类文献——尤其是被广泛转引的设计参考页——把交错点从**绘图语法**降维为**风格滤镜**，从而在方法论层面误导了复现实践。本文进一步提出交错点的五种功能类型（色调桥接、形体转向、褶皱应力、投影遮蔽、材质纹理），并给出可操作的六步流程与量化验收指标。文章主张：PC-98 的交错点不是覆盖在已完成明暗之上的纹理，而是面与面之间的过渡带本身；平面的纯色与边界的点阵共同承担造型，缺一不可。本文第 2–7 节以 1985–1992 年的 16 色期为主要对象；第 9 节补论 1993 年后 PEGC 的 256 色模式，并说明它如何改写上述结论。

**关键词**　PC-98；像素画；交错点；Bayer 抖动；索引色；视觉小说；技术误读

---

## 1　引言：一次失败的复现

最初的任务是生成“PC-98 galgame 风格的立绘和背景”。第一版直接以提示词要求模型“16 色、可见抖动、640×400 质感”；第二版改用更规范的后处理：把高清图缩到 640×400，吸附 12bit 调色板，再以 8×8 Bayer 矩阵对全图做有序抖动。

从技术指标看，第二版是“正确”的：画布 640×400，全画面恰好 16 色，每个通道都是 17 的倍数（对应 PC-98 的 4bit/通道、4096 色硬件规格）[5]，立绘 256×290[5]。但从画面看，它是错的：天花板、墙面、桌面布满均匀噪点；脸部先有三级灰阶，点再浮在其上；衣服上的点阵方向与袖褶毫无关系；立绘与背景的点阵甚至周期对齐，像同一张网罩住了两个图层。

批评一语中的：**PC-98 图像使用交错颜色的点，是为了表达不同状态（如皱褶），而不是把阴影做好之后在表面撒点混合。**

这句话指向的不是参数问题，而是抽象层级问题：抖动究竟发生在“绘制”阶段，还是“后期”阶段。本文即围绕这一区分展开。

## 2　文献与方法

### 2.1 分层判据

判断一篇文献是否真正讨论“绘图方式”，本文采用三个问题：

1. 它是否说明点**放在哪里**（平面内部、色阶交界、投影区，还是“全图”）；
2. 它是否说明点**朝哪个方向排列**（沿形体、沿透视、沿褶皱，还是固定 45° 棋盘）；
3. 它是否说明**密度如何变化**（表示过渡程度，还是表示“风格强度”）。

三个问题都能回答的，归为过程性证据；只能回答“看起来怎样”的，归为表征性描述。二者的可信度并不对等：前者可指导生产，后者只可作视觉核对清单。

### 2.2 负面文献：滤镜话语的四种症候

被搜索排名推到前列的，多为“设计参考”类页面。它们描述准确、排版友好，却在关键处完成了概念偷换。

**（1）定义偷换：把“看起来像渐变”当作“制作目的是渐变”。**

[6] 写道：“Artists placed pixels individually, exploiting dithering patterns to simulate smooth shading, soft skin tones, and atmospheric lighting”。句中“placed pixels individually”承认了手工性，但随即把目的归结为“模拟平滑明暗”。于是读者得到的推论是：先有平滑明暗，再用点去模拟它——正是本文要否定的顺序。

**（2）全称量化：“used everywhere”。**

同页称抖动“used everywhere to simulate gradients”，并断言“Without visible dithering patterns, the result will look like generic dark-mode anime, not PC-98”[6]。这一句把“局部语法”升格为“全局必备纹理”，直接为全图 overprint 提供了合法性。

**（3）参数化脱域：把语义量当成滑杆。**

[8] 的建议最为典型：“Dithering Strength: Crank it up to 60% - 100%”、“Embrace the noise”、“Bayer … non-negotiable”。在这里，密度不再是“两种色阶之间过渡到几成”，而是“风格强度”；点阵不再是形体的函数，而是画面的滤镜参数。

**（4）媒介错位：为 CSS 复现而总结。**

[6][7] 都提供了“Dithered Gradient Simulation Pairs”表格，用两组十六进制色值配对模拟皮肤、夕空、布料阴影，并以 `repeating-linear-gradient` 实现棋盘纹理。这种方法论上并无问题——它服务的是网页视觉——但一旦被反向当作“PC-98 画法”，就会只剩“可见的网格”，丢掉方向与语义。

值得注意的还有文献的同源性：[6] 与 [7] 的条目措辞高度重合（“High-resolution pixel art at 640x400”“Heavy dithering”“Limited color palette”等），说明这一“负面经典”并非多源独立观察，而是同一份清单的多次转载。转载次数制造了权威感，却没有增加关于绘制过程的证据。

需要公平地指出：[7] 中仍残留一句过程性描述——“Hair rendered with highlight bands -- 3-4 color steps from dark base to bright highlight, dithered at transitions”。这句其实是对的：**只在色阶段之间抖动**。但它被淹没在“all transitions achieved through dithering patterns”的总体框架里，读者很难据此建立正确的操作顺序。这正是“框架压倒细节”的典型案例。

### 2.3 正面文献：过程性证据

**（1）教程类：先硬边，再桥接。**

[2] 的结构最为清晰。它先给出基线：“Hard cut — 0% dither … Keep this for a crisp edge or a deliberately flat shading style.”随后以圆柱为例分步操作：先让受光关系可读，再“Replace the split with a checkerboard”，并且明确限定范围——“On the side only”；再“Vary the coverage”，用 75% → 50% → 25% 的光点比例把过渡推向暗侧；并给出密度语义：“25% … darker side of a transition”“75% … near the bright end”。

这段教程实际上给出了本文所需的三要素：位置（只在 split 处）、方向（沿圆柱转向）、密度（表示过渡比例）。它没有讨论褶皱，但方法论可以直接迁移。

**（2）立体感类：边界不能是直线。**

[3] 指出两个典型失败：枕状阴影（pillo shading）与带状分层（banding）；并强调“明度段階の切り替えを直線で置くと等高線のような縞……境目はジグザグに崩し、不規則な形でまたぐようにします”。换言之，**边界本身要被形体打碎**，而点阵正是打碎边界的工具之一。该文还主张暗部做 HSV 色相偏移、以 1–2 像素反射光提亮轮廓——这些都与“先分面、再过渡”的顺序一致。

**（3）材质类：警惕无意义噪点。**

[4] 在讨论布料与头发时写道：“Shading adds depth, but can also create needless noise if not done well.”这句话虽短，却准确命中了本文复盘中的现象：布料是噪点最容易失控的区域，因为褶皱密集、方向多变；若点阵不跟随褶向，就会退化为噪声。

**（4）实录类：唯一接近一手实践的证据。**

[1] 是一位画师完整绘制 PC-98 风格室内背景的 speed paint 转写（原始录制约 4 小时，加速 18 倍）。其中与本文直接相关的有四条：

- “using the dithering brushes to make the patterns **parallel to each other** … where the lines are that I want to use as a guideline”——点阵成组平行，并以辅助线（透视/形体线）为基准；
- “a white dithering gradient is added to the table … it goes from **less dense to more dense**”——密度沿受光方向渐变，而非全屏统一；
- “adding dithering patterns **to where there should be shadows** so like on the side of the pillows”——先判断阴影，再决定落点；
- 榻榻米“done by rotating a dither pattern a bit like when you overlay **screentones**”——点阵还可承担材质语义，接近网点纸。

同一实录还提到以《YU-NO》的截图作为点阵参考[1]。这说明画师的工作流中存在“参考—抽取图案—按形体排布”的中间环节，而不是套用一个全局矩阵。

**（5）规格类：只作约束，不作美学依据。**

[5] 提供了可靠的工程参数：背景 640×400、立绘最大 256×290、单屏 16 色、最近邻转换、index 0 透明；其示例调色板的每个通道值均为 17 的倍数，印证了 4bit/通道。这些是“边界条件”，不能回答“点该放在哪”，因此本文仅将其用于验收，不用于风格论证。需要说明的是，16 色/4096 色属于 1985–1992 年的规格；1993 年后 PEGC 的 256 色模式改变了色彩预算，详见第 9 节。

## 3　交错点的功能类型学

综合上述证据，可将 PC-98 图像中的交错点按语义分为五类。分类的意义在于：**同一视觉现象可能对应完全不同的绘制决策**，仅凭成品截图无法区分，这正是表征性文献失效的根源。

### 3.1 色调桥接（tonal bridge）

两个色阶平面相邻时，用 25%–75% 的点阵在交界带内制造第三视觉色调。带宽与过渡的陡缓成反比：转折越平缓，带越宽。带外必须是纯色。

### 3.2 形体转向（form turn）

圆柱、球面、布料包裹的肢体在转向背光时，点阵沿**等照度线方向**排列，其密度沿光照梯度单调变化。点阵的“行”应大致平行于形体的切线，而不是屏幕坐标。

### 3.3 褶皱与应力（fold & stress）

这是本次争议的核心。布料的褶皱由三部分构成：脊线（受光的凸起）、谷线（遮蔽的凹陷）、以及两者之间的过渡面。过渡面不是均匀渐变，而是被压缩成 1–2 个色阶；点阵沿褶皱的**走向**成组排列，密度在谷侧升高、在脊侧降低。点的疏密因此直接编码“此处布面向内折了多少”，而不是“此处有多暗”。

褶皱在此不是“阴影的一种”，而是**几何事件**；点阵是它的量词。

### 3.4 投影与遮蔽（cast shadow / ambient occlusion）

桌下、发梢内侧、身体与背景之间，点阵带沿着投影边缘生长，边缘一侧密度高、向光侧衰减。它与 3.3 的区别在于：投影由遮挡关系决定，形状服从光源与物体轮廓，而非布料力学。

### 3.5 材质纹理（material）

榻榻米、石材、砖墙、织物经纬可使用旋转过的图案，效果接近网点纸[1]。此类用点**允许出现在平面内部**，但必须满足两个条件：图案成组、可解释为材质；且不与其他语义的点混用。本文此前的错误不在于“平面有点”，而在于平面上的点**不承担任何语义**。

### 3.6 三元组判据

由此可把“是否正确使用交错点”收敛为一个三元组：

> **位置**（是否落在需要过渡/材质的位置）× **方向**（是否沿形体、透视或褶皱）× **密度**（是否表示过渡程度）

三者任一失效，点阵即退化为滤镜。全局 Bayer 的问题正是三项同时失效：位置全图、方向固定、密度恒定。

## 4　误读的发生机制

为什么大量二次文献会集体写成“滤镜”？本文认为有四层原因。

**（1）从结果反推方法。** 截图只能提供颜色统计与纹理外观，无法提供笔序。观察者看到“大片点阵”，最经济的解释是“加了一层纹理”；而“先分面、再沿边界铺点”需要过程知识才能推断。归纳成本决定了误读的方向。

**（2）为可复制性而参数化。** 网页与工具需要可执行的规则，“强度 60–100%”“颜色对 A/B”比“沿褶向成组排列”更容易实现。参数化在传播中胜出，语义在传播中丢失。

**（3）全称量化的修辞收益。** “used everywhere”“non-negotiable”这类表述能快速建立风格辨识度，也便于做视觉演示；代价是把局部语法绝对化。

**（4）生成式 AI 的 prompt 化。** 当“PC-98 style, 16 colors, dithering”成为提示词，模型学习到的是**外观分布**，不是**绘制顺序**。这也是本文第一版失败的直接原因：提示词与后处理都在“外观层”操作，从未在“笔法层”操作。

四层原因叠加，形成了本文所称的“滤镜化误读”：一种由设计参考、工具教程与提示词共同维护的、自我循环的共识。

## 5　方法论重构

基于第 3 节的三元组，复现流程应调整为以下六步。每一步的产物都可被检查，避免再次滑回外观层。

**S1　形体与光源先行。** 只画硬边色块，不画渐变；确定单一主光源与反射光位置。此阶段不出现任何点阵。

**S2　色阶压缩与色相偏移。** 每种材质压缩到 2–4 阶；暗部向蓝紫偏移、亮部向黄偏移[3]，避免用灰压暗。

**S3　调色板吸附。** 全屏 16 色，通道值吸附到 17 的倍数，保留黑、白、强调色、肤色等功能位[5]。

**S4　边界带提取。** 以相邻色阶的等值线为中心生成过渡带；带宽由原过渡的梯度决定。带外强制纯色。

**S5　方向场与褶皱。** 用局部结构张量估计形体切向，点阵主轴沿切向排列；褶皱另行绘制脊线/谷线，点阵在谷侧加密。禁止全局固定角度的棋盘。

**S6　密度映射与人工修整。** 带内密度按 25/50/75 三档映射过渡比例；随后人工删除散点、拉直成组、对齐辅助线[1][2]。

**验收指标（可量化）：**

1. 平面噪点率：平坦区域（梯度模长低于阈值）内的点像素占比，应接近 0（材质区除外）；
2. 方向偏差：点阵主轴与局部切向的夹角中位数，宜小于 30°；
3. 语义点率：可被归入 3.1–3.5 任一类别的点像素占比，应接近 100%；
4. 色阶数：单一材质内不超过 4 阶；
5. 调色板：全屏 ≤16 色且通道值为 17 的倍数；
6. 跨图层一致性：立绘与背景的点阵不得共享同一相位（否则会出现“同一张网”）。

## 6　对既有产出的复盘

以三元组逐项检查第二版成品，可定位具体失效点：

| 区域 | 现象 | 失效维度 |
|---|---|---|
| 天花板、墙面 | 大面积均匀网纹，无过渡对象 | 位置（平面内）、密度（恒定） |
| 桌面与地面 | 网纹方向与透视无关 | 方向 |
| 脸部 | 先有三级灰阶，点浮于其上 | 位置（未落在交界） |
| 制服袖褶 | 点阵为全局 45°，与褶向无关 | 方向 |
| 夕阳天空 | 全片同密度网格 | 密度（未表达受光） |
| 立绘/背景 | Bayer 相位对齐 | 跨图层一致性 |

其中“先有灰阶再撒点”是最本质的一项：它说明管线在 S1 之后直接跳到了 S6，S4 与 S5 从未发生。缺少的正是“把边界当作形体事件来处理”的环节。

## 7　局限与后续工作

本文的证据结构并不均衡：过程性证据仅有一份完整实录[1]与若干教程[2][3]，样本量小，且集中于单一画师；对“褶皱由点阵编码”的论断，目前主要依赖视觉推断与方法论一致性，尚缺一手画师的明确表述。后续工作应包括：

1. 收集《YU-NO》等原作的原始截图，在 1× 与 4× 两种尺度下标注点阵带的位置、方向与密度，建立小型语料；
2. 寻找 1990 年代日本同人技法书或画师访谈，检验“褶皱=点阵量词”的表述是否存在于当时话语中；
3. 以本文六步流程制作 128×128 的袖口/裙褶局部样本，用第 5 节指标评估，再决定是否扩展到整图；
4. 若继续使用生成模型，应把它限制在 S1–S2（色块与光源），S4–S6 必须由几何与方向场控制，而不是再一次全局抖动。

## 8　结论

PC-98 图像中的交错点，是索引色绘画在极端色数下的**过渡语法**：它标记面与面之间的交接，编码形体的转向、褶皱的深浅、投影的软硬与材质的组织。它的意义由位置、方向、密度三者共同决定；去掉任一维，点阵就退化为纹理。

以设计参考与工具博客为代表的二次文献，把这一语法描述为“模拟渐变”的全局滤镜，并通过互相转引形成了看似权威的共识。这种描述在网页复现的语境中有效，在绘制与生成的语境中则是有害的：它引导实践者在错误的抽象层（外观层）操作，产出“有 PC-98 纹理、无 PC-98 造型”的图像。

因此，正确的复现顺序不是“画好—撒点”，而是“分面—定界—沿形体铺点—平面归零”。交错点不是画面的表皮，而是形体的句法。

## 9　补论：256 色期（PEGC）与画法的改写

前八节围绕 16 色期展开，但 PC-98 的图像史并非只有 16 色。1992 年 PC-9821 系列登场，随后的 PEGC 把同屏色数提高到 256，直接改变了绘画的预算结构。若忽视这一分期，用 16 色的方法去逼近 256 色期的画面，就会再次落入“预算错配”的陷阱——这正是本文实践中的第二个错误来源。

### 9.1 硬件事实

| 项目 | 16 色期（1985–1992） | 256 色期（1993–1996，PEGC） |
|---|---|---|
| 同屏色数 | 16 | 256 |
| 调色板 | 4096 色（4bit/通道） | 1677 万色（24bit）中选 256 |
| 分辨率 | 640×400 | 640×400（2 画面）或 640×480（1 画面） |
| 显存 | 视机型 | 512KB |
| 显存访问 | 平面（GRCG/EGC） | packed pixel（1 字节 = 1 索引）与 planar 两种，planar 仅部分机型支持 |

需要澄清两点。其一，PC-9821 系列虽始于 1992 年，但 256 色模式主要随 98MATE（PC-9821Ap/As/Ae）普及，技术资料多记为 1993 年[11][12]。其二，PEGC 仍保留 16 色兼容模式，因此“PC-98 = 16 色”的印象在 1993 年后依然成立——那是兼容模式，而非硬件上限。

### 9.2 对前文结论的限定

第 3–5 节关于“交错点是面与面之间的过渡语法”的论断，在 256 色期依然成立，但**权重下降**：

- 16 色期：不抖动就没有中间色，抖动是造型的**主要手段**；
- 256 色期：中间色可以直接用邻近色阶画出，抖动退为**材质、光晕与阶间过渡**的辅助手段。

因此，“平面零抖动”的绝对表述应修正为：**每一个点都必须可解释**——是异色混色、材质纹理，还是光晕渐变；解释不了的点才是噪点。

### 9.3 色彩预算

256 色不是“16 色 × 16”，而是按材质分族、按明度分阶：

| 用途 | 建议色数 | 结构 |
|---|---|---|
| 肤色 | 14–18 | 亮/中/暗 + 腮红 + 藕荷异色影 + 反射光 |
| 头发 | 18–24 | 3 个色相段（蓝黑 / 酒红 / 奶油高光）× 6–8 阶 |
| 制服 | 18–24 | 靛蓝 → 紫蓝暗部 → 淡紫受光 |
| 白色布料 | 8–10 | 米白 → 奶油影 → 淡蓝紫影 |
| 背景 | 80–120 | 天空、墙面、地面各 4–8 阶渐变 |
| 强调 | 8–12 | 正红、金、黄绿、绿 |
| 线/黑 | 4–6 | 深蓝黑、深酒红、纯黑（仅睫毛与最深处） |

同一材质从 3 阶扩展到 6–10 阶后，暗部不再只是“更暗的基色”，而是**色相偏移后的另一族颜色**：皮肤转藕荷，蓝布转紫蓝，白衣转奶油与淡紫，绿布转暖灰绿。

### 9.4 绘制顺序

1. **线稿**：1px；线色取该物体最深的色相，不用纯黑。
2. **定色相族**：先列 8–10 个族，每族定“亮/基/暗”三个锚点，再在锚点间插值出中间阶。
3. **平涂基底**：每区域一个基色。
4. **分面**：按主光源切 2–4 个硬边面，面间不渐变。
5. **面内做体积**：用同族 4–8 阶邻近色画出柔和变化，这一层**不需要抖动**。
6. **阶间过渡**：仅在阶与阶的交界铺 1–2px **异色**点阵，打断生硬的色阶线，保留手绘颗粒。
7. **高光与边缘光**：高光两阶（奶油白 + 少量纯白点）；暗侧 1px 冷色边缘光。
8. **背景**：整体降饱和、降对比；大渐变用实色阶，砖、木、布等材质用点阵纹理。
9. **统一**：全图吸附到 256 索引，检查每个材质是否落在自己的色相族内。

### 9.5 “脏”的新判据

- 相邻阶**色相相同、只降明度** → 脏（泥）；
- 阴影**饱和度掉到接近灰** → 脏；
- **暖光区出现冷灰影** → 脏；
- 反之，只要每阶都带明确色相偏移，即使阶数多也不会脏。

### 9.6 对第 5 节六步流程的修订

| 步骤 | 16 色期做法 | 256 色期做法 |
|---|---|---|
| S2 色阶压缩 | 每材质 2–4 阶 | 每材质 6–10 阶，先定色相族再插值 |
| S4 边界带 | 以等值线为中心生成过渡带 | 阶内用实色，仅在阶间保留 1–2px 过渡 |
| S5 方向场 | 点阵沿形体切线成组 | 体积靠色阶走向，点阵只用于纹理与阶间 |
| S6 密度映射 | 25/50/75 三档铺满阴影 | 抖动密度大幅降低，不再承担明暗 |
| 验收 | 平面噪点率、方向偏差、语义点率 | 增加“每材质阶数”“暗部色相偏移量”“中性灰占比” |

### 9.7 共同底层与局限

两期的底层顺序并未改变：**先分面，再换色相，最后才动点**。变化的只是“中间色由谁生产”——16 色期由点阵生产，256 色期由色阶生产。

本节的局限在于：PEGC 的具体用色上限与各作品的实际色数，仍需以原始截图逐帧统计；不同厂商、不同年份的差异可能很大，本文给出的是可操作的预算框架，而非历史平均值。
