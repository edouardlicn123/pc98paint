# PC-98 人物的做法：立绘与内嵌人物

> 三篇系列之三。总论见《PC-98 图像风格总论：索引色绘画的合成语法》，场景见《PC-98 场景的做法：空间、材质与光》。

## 摘要

人物在 PC-98 画面里分两类：被拉近、需要从背景切出的**前景立绘**，以及服从透视与景深的**场景内嵌人物**。前者用 1px 深色硬线、高局部对比、1–3px 窄交错；后者退回世界层参数，无描线、低对比、色块剪影。本文给出面部、头发、服饰、手与道具的逐项画法，强调“每材质 3–5 阶”“暗部换色相”“小结构回退实色”，并说明 256 色期的色数余量应花在材质种类与表情差分上，而不是堆深每材质的阶数。

关键词：立绘；半身像；表情差分；交错带；索引色人物

---

## 1　两类人物与三层参数

| 参数 | 前景立绘 | 场景内嵌人物 |
|---|---|---|
| 描线 | 1px 深色硬线 | 无或极细 |
| 局部对比 | 高 | 低 |
| 交错带宽 | 1–3px | 随场景 |
| 图案 | 方向性窄带 + 装饰纹 | 极简 |
| 细节 | 集中于脸与衣褶 | 色块剪影 |
| 背景 | 抽象平色/网点 | 服从透视与景深 |

判断标准是**观看距离与图层角色**，不是“画的是人”。走廊里的人物即使衣着完整，也应压成低对比色块；半身像即使只画到胸口，也要升级为立绘参数。混淆两者，会得到“贴”在场景上的立绘，或“糊”成一团的内嵌人物。

## 2　前景立绘的规格

- 16 色期常用 256×290 以内，index 0 透明；256 色期可利用双画面，立绘单独一页[5]。
- 构图多为腰上或膝上；头顶留 8–16px，脚下与对话框留接触空间。
- 描线 1px，颜色用该物体最深的色相（深蓝黑、深酒红），不用纯黑；受光处可断开。
- 背景抽象化：平色、双色分割、网点纸。立绘背景不承担空间，避免与表情抢读。

## 3　面部

面部只允许三个层次，多则脏：

1. **底色**：桃、珊瑚、土黄，按角色肤色定；
2. **异色暗部**：藕荷、玫红、红褐，覆盖刘海下、下颌、颈部、鼻侧；形状是硬边块，不是渐变；
3. **腮红**：另一支粉色，以点簇或小面积交错出现，与肤色混合，而不是叠加半透明。

边界处理：暗部与底色之间用 1–2px 交错，密度向暗部递增；脸颊圆弧处密度带略宽，下颌处略窄。鼻梁不画高光带，只在鼻头点一小块亮色；嘴唇用 1–2 个实色，嘴角用短线。

耳朵是常被忽略的体积：耳廓亮、耳甲暗，暗部同样换色相（红褐/紫），交界用窄交错。

## 4　眼睛

眼睛是“实色优先”的典型：

- 虹膜：深栗/深蓝实色，内部 1–2 块高光（奶油白，不用纯白）；
- 眼白：米白或极浅的蓝灰，靠上眼睑处压一条窄影；
- 睫毛与上眼线：纯黑或近黑实色，1px；
- 瞳孔与虹膜交界：可用 1px 交错，但面积小，多数情况直接实色更清楚。

原则：**小于约 10×10 像素的结构，交错会破坏可读性，一律实色。**

## 5　头发

头发的体积不靠多阶，而靠“主体实色 + 块状高光 + 异色暗部”：

- **主体**：近黑发用蓝黑，棕发用红棕；大面积保持实色，不铺噪点；
- **高光**：奶油白/淡黄，成组、成束，边缘呈锯齿或阶梯，不用柔化；高光带宽度 1–3px，沿发流方向；
- **暗部**：换色相——黑发转酒红/紫，棕发转深红褐；与主体之间用窄交错；
- **发梢**：分成若干束，束间留底色或暗色，末端可散 1–2 个像素，制造细节而不增加色数；
- **刘海投影**：额头上是一条硬边暗块，边缘 1–2px 交错；不要画成渐变。

黑发最容易画“死”：主体与线稿同为近黑时，必须在暗部或高光里引入紫/酒红/奶油，否则头发会变成一块没有体积的黑块。

## 6　服饰

每个材质 3–5 阶，结构固定：

| 材质 | 亮 | 基 | 暗（换色相） | 交错 |
|---|---|---|---|---|
| 藏青制服 | 蓝 | 靛蓝 | 紫蓝/黑蓝 | 1–2px 棋盘 |
| 白衬衫 | 米白 | 白 | 奶油黄 + 淡蓝紫 | 窄带，两段影 |
| 绿领结 | 黄绿 | 橄榄 | 墨绿 | 沿结体方向 |
| 红缎带 | 朱红 | 正红 | 酒红 | 褶皱两侧 |
| 棕皮革 | 浅棕 | 中棕 | 深红棕 | 边缘窄带 |

要点：

- **暗部不是“更暗的基色”**，而是色相偏移后的另一族颜色；
- **白布有两段影**：靠近受光处偏奶油，背光处偏淡蓝紫；只用灰会脏；
- **褶皱用密度场**：褶脊两侧各一条密度带，亮面窄、暗面宽；褶谷可用更冷的配对色；
- **大面积暗面内部也要铺少量交错**，否则整块填色会“死”；密度低于交界带，方向沿曲面。

## 7　小结构回退实色

以下结构一律实色，不铺交错：

- 眼、眉、唇、鼻孔；
- 纽扣、领结结心、缎带扣、发饰；
- 指甲、鞋扣、眼镜框；
- 高光核心与最深的缝隙。

面积阈值：前景立绘约 10×10 像素以下；场景内嵌人物约 4×4 像素以下。超过阈值才考虑交错。

## 8　图案族

同一套“配对 + 密度 + 图案”，在人物上有三种笔触：

1. **发丝线组**：沿发流的短线/斜线，成组平行，末端阶梯；
2. **布料棋盘/斜纹**：沿褶向的 2×2 或斜向交错，密度表达受光；
3. **装饰印花**：头巾的锯齿、制服的条纹，属于图形而非明暗；必须与体积交错分开管理，不能用来解释阴影。

参考图中男生的红紫锯齿头巾，是装饰印花；把它误读成“面部阴影的画法”，就会画出花纹脸。

## 9　手与道具

- 手：手背亮、指缝暗，暗部偏红褐/紫；手指交界 1px 交错即可，指节不画高光带；
- 道具：书包、杯子、武器按场景材质配方处理，但对比略高于背景，低于人物面部；
- 手持物与手的接触处加深色窄带，否则会“浮”。

## 10　表情差分与色板管理

- 同一角色共享一套原色族，只替换眼部、嘴部与腮红的小块索引；
- 256 色期把立绘放独立画面页，表情差分只改局部，减少重绘与显存占用；
- 差分之间保持肤色、发色、制服色完全一致，避免“换脸变色”；
- 色数余量优先给“更多材质与差分”，而不是“每材质更多阶”。

## 11　流程

1. 定图层：前景立绘或内嵌人物；
2. 定尺寸、构图、透明区；
3. 线稿：1px 深色线，受光处断开；
4. 定原色族：皮肤、头发、每件服饰、道具；
5. 平涂基底；
6. 按主光源分面：每材质 2–4 段，暗段换色相；
7. 面部：底色 + 异色暗部 + 腮红点簇；
8. 头发：主体实色 + 成组高光 + 异色暗部 + 发梢分束；
9. 交界铺 1–2px 交错，方向沿形体；暗面内部少量补点；
10. 小结构回退实色，加高光核与边缘光；
11. 吸附索引，检查脏区、可读性、色相一致。

## 12　验收

- 每材质 3–5 阶，暗部色相偏移 ≥30°；
- 中性灰占比低，白布阴影为奶油/淡紫而非灰；
- 眼、唇、纽扣为实色；
- 交错带宽度 1–3px，方向与形体夹角中位数 <15°；
- 头发至少有 1–2 组成组高光，且高光非纯白；
- 缩小到 50% 后，五官仍可读；
- 与场景合成时，人物对比高于背景均值。

## 13　案例

**男生半身像**：土黄皮肤 + 红褐暗部；墨绿近黑发，亮部为块状发束；红紫锯齿头巾属装饰印花；绿外套 3 阶；背景为米黄网点纸。说明“装饰纹与体积纹必须分开”。

**女生半身像**：浅棕发 + 近白奶油高光（锯齿分组）+ 深棕暗部；紫西装亮/中/深藏紫，交界 1–2px 棋盘；白领米白 + 蓝灰影；绿领结黄绿高光 + 墨绿暗部；背景粉/浅蓝平色分割。说明“3–4 阶 + 窄交错”在 256 色期仍然是人物画法。

**走廊内嵌人物**：无描线、低对比、色块剪影，随场景参数。说明“人物画法由图层角色决定”。

**肥宅是第三个轴（体型），不是年龄或性别的延伸**：他的臂展轮廓 3.4 头高、脸宽 2.07 头高、颈 0.05，三项全部越界——按旧规则会被读成“极成年男性”，实际却是软弱的宅男形象。所以模型必须是 **年龄 × 性别 × 体型** 三轴：前两轴定骨架（肩宽段、胯线），体型轴（瘦 / 壮 / 肥）单独叠加宽度与下颌膨胀。肥满体的头**宽大于高**，不能用脸宽/头高这一比值判断，需改看脸宽/脸高。

两个不同人物、不同朝向，六项指标全部落在 5% 内。由此得到可用的腿部刻度（女高中生，≈6.2 头身）：

- **腿长（胯→脚底）= 3.7 头，占全身 59%**
- **大腿（胯→膝）= 1.6 头；小腿（膝→踝）= 1.5 头；脚 = 0.5 头**
- 大腿 ≈ 小腿，"小腿短"不是 PC-98 的常规做法
- 膝线固定在 **4.2 头**，是除胯线外第二个可靠的水平刻度

1. **之前所有“推算头身比”基本正确**：女高中生推算 6.5，实测 6.2。
2. **肩宽比随取景变化**：远景全身量到 1.06–1.16（背面）/ ≈1.7（正面含袖），与半身的 1.1–1.5 不同——因为远景量到的是袖子与手臂外缘。所以 **1.5 那条断口只在“同取景、同姿势”内有效**，不能跨景别比较。

**结论：从三视图出立绘时必须主动拉长。** 设定稿为了塞进纸张、保留大头大眼的辨识度，画得矮；实际游戏立绘会把腿多拉 20–40%，总头数从 5.4 提到 6.2。如果照三视图的比例直接描，立绘会明显“头大身子短”。

具体换算（把 5.4 头身的设定稿转为 6.2 头身立绘，保持头高不变）：

- 膝线：3.87 → **4.2**
- 脚踝：4.95 → **5.7**
- 大腿：1.34 → **1.6**
- 小腿：1.08 → **1.5**

即**躯干（头顶→胯）几乎不动（2.53 → 2.56），多出来的 0.8 个头全部加在腿上**。这与“矮小只压腿长、不压躯干”是同一条规律的两端。

| 项 | 萝莉设定稿 | 高中生设定稿 | 游戏远景 |
|---|---|---|---|

**萝莉与高中生差的 0.9 个头，全部落在膝线以下**：膝线降 0.67、脚踝降 0.95，而大腿与小腿是**同时缩短**的（不是只压小腿）。所以做萝莉时不能只砍小腿，要把大腿一起压到 0.8 头。

**肩宽是轮廓量，不是骨架量。** 同为高中男性，① 张臂穿开襟外套测出 2.00，宅男垂臂穿紧身立领测出 1.55，差 23%，但骨架几乎相同。要比较骨架，应以三角肌外缘而不是袖子外缘为准；轮廓肩宽只能用于“这一帧画面占多宽”。

**高中男生四连（①41%/0.72、高个 47%/0.76、③51%/0.77、④49%/0.66）说明眼线和脸宽并不绑定。** ③ 和 ④ 眼线都接近 50%，但 ③ 是宽脸 0.77、④ 是窄脸 0.66；两者读感完全不同，靠的是配饰与服装：③ 墨镜 + 夹克 → 不良，④ 眼镜 + 立领 → 优等生。所以气质是三个独立旋钮：

- **眼线**（低=软 / 高=硬）
- **脸宽**（窄=文 / 宽=武）
- **配饰服装**（墨镜、眼镜、立领、开襟）

拨不同的组合就得到不同人设，骨架代码不用改。

**成年男性眼线集中在 49–51%，但可以冲到 60%**（五连：老师 51%、员工 49%、父亲 50%、中年男性 50%、企业职员 60%）。前四个正好落在头高中线上，是真实解剖位置；企业职员是长下颌的硬派画风，眼线被顶到 60%。所以准确表述是：**49–51% 是成年男性的默认值，60% 是同一旋钮的硬派上限**，而不是所有成年男性都锁在 50%。**“年长”不是靠把骨架变宽**：父亲的轮廓肩宽 2.7 里大部分是毛领，颈短是胡须遮的，真正传达年龄的是眼线、鬓角/胡须和下垂的嘴角。

高个员工是唯一露出腰线的男性：皮带在 3.41 头高、裁剪在 3.97 头高，反推 ≈7.5 头身，比其余男性高约半个头。

**眼线高度（33–67%）不能用来判年龄，也不能判性别。** 最低的是成年职业女性（33%），最高的是肥宅（67%，下颌膨胀）；同为高中男生也从 41% 到 51%。它更像一个画风/气质开关：偏低 = 柔，偏高 = 硬。真正稳定可用的只有两个量：

- **脸宽 / 头高**：幼态 0.60–0.67，成熟 0.72–0.77
- **肩宽 / 头高**：少女 1.1，成年女性 1.6–2.1，男性 1.5–2.4（随姿势浮动）

其他趋势：

- **胯线 / 头高**：2.43 → 2.68 → 3.04 → 3.49。越成熟躯干越长、头越小。
- **脸宽 / 头高**：0.60 / 0.66 / 0.72 / 0.67 / 0.67 / 0.72 / 0.76 / 0.77。多数落在 0.60–0.67（幼/柔）或 0.72–0.77（成熟/美型），但**女高中生③ 以 0.72 落在成熟区间**——脸宽同样受画风支配，不能单靠它判年龄。
- **宅男辨识不在比例，在姿态**：圆肩、头前倾、颈最短（0.15 头高）、下颌内收。像素上就是“肩线下溜 + 头偏 1–2px + 脖子压到 4–5px”。

已确认的硬约束：

- **肩宽**：少女 ≈1.1 头高（1.7 脸宽），成年女性 1.6–2.1（2.3–2.7 脸宽），男性 1.5–2.4（随姿势）。
- **胯线**：萝莉/少女 2.4–2.7 头高，成熟女性 ≈3.0，男性 ≈3.5。低于 2.4 偏幼。
- **眼线 33–51%**：只在同性别、同年龄段内部当气质参数用，不可跨组比较。
- 头部越大，肩越要收窄；只放宽肩会立刻变成成人骨架。

判定不了的部分：

- **腿长已实测三档**：游戏内远景（女高中生 6.1–6.3 头身，膝线 4.2、脚踝 5.7、腿占 59%、大腿≈小腿≈1.6 头）、高中生三面図（5.4 头身，膝 3.87、踝 4.95、腿占 53%、大腿 1.34）、萝莉三面図（4.5 头身，膝 3.2、踝 4.0、腿占 44%、大腿≈小腿≈0.8）。**从设定稿出立绘要主动拉长 15%；做萝莉要把大腿小腿同时压到 0.8 头。** 成年女性与男性的腿部刻度仍缺。
- 萝莉与高中生的骨架差异只有“上身/头”这一条（约 10%），其余肩腰脸比例一致。萝莉感主要来自头眼画法、发型体积与服装，不是肩腰比。
