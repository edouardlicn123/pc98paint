# 08 人设锁定与重新出图（devdoc）

2026-11-22。解决"人设只存在图片里、生成时自由发挥"的问题。

## 1. 问题

| 现象 | 根因 |
|---|---|
| 同一角色每次发型不同 | 人设没有编码成字段，提示词靠手写 |
| 提示词写的是 A，spec 写的是 B | 管线复用了别的角色的 spec，只为拿 lint 阈值 |
| 三视图与立绘不像同一人 | 三视图从未被拆成规格，生成时无从对照 |

## 2. 规则

1. **一份角色一份 spec**：`characters/<id>/spec.json`，逐项从三视图抄写，禁止自由描述。
2. **生成顺序固定**：三视图 → spec → 立绘源图 → 管线。
3. **提示词只从 spec 取字段**，不允许在提示词里临时新增人设（发色、发型、配饰）。
4. **三视图为白底、全身、三视角**；背景/场景属于管线 3，不混进人设图。
5. **立绘默认半身、无表情、平视**；特写与全身只在明确指令下生成。
