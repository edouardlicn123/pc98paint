# 07 管线整改（devdoc）

记录 2026-11-22 立绘管线整改的目标、阶段、验收与回退方式。执行顺序不可跳步，每阶段验收通过后再进入下一阶段。

## 0. 背景

问题不是孤立 bug，而是三层错位：

| 层 | 症状 | 根因 |
|---|---|---|
| 源图生成 | 右眼无高光、俯视、半身重画脸 | 负面词禁止高光；提示词写死 `full body`；无档位/表情/机位字段 |
| 角色锁定 | 三档不像同一人 | 每档独立文本生成，无参考图，无主脸派生 |
| 像素转换 | 白领沾肤色、制服污渍、袖口发紫 | 逐像素阈值代替材质区域；无布料暗档；白衣冷阴影无槽位 |

## 3. 制服暗部规则（本阶段确定）

1. 暗部 = 右侧轮廓内侧竖带，`k = 图宽 × 2%`；
2. 内部不产生孤立暗块，暗带必须贴真实剪影；
3. 裁切边不是轮廓，不产生横向暗带；
4. 裁切带内只保留从上方连续延伸的竖向暗带；
5. 白衣、头发、绿丝带暂不套用，稳定后再评估。

验收指标：`navy_dark` 到剪影最大距离 ≤ `k+1`；底部 5 行暗像素 ≤ `2k`。

## 4. 每张出图验收清单

1. 单档、单表情；
2. 平视，无俯仰；
3. 两眼虹膜 + 高光都在，同侧、纯白、尺寸差 ≤1px；
4. 白领区无肤色；
5. 制服暗部只在右侧轮廓，内部无暗块；
6. 底部无横向暗带；
7. 12±2 色、中性灰 0；
8. 与设定图同脸、同衣设。

## 5. 风险与回退

- 新逻辑全部在开关后，默认关闭，旧路径保留；
- 提示词改动只动高光与机位，不改整体风格词；
- 色板暂不新增槽位，维持 16 色结构；
- 任何色板槽位、量化阶段、抖动策略、裁切构图的改动，先征询再执行。
