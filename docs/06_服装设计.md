## 2 七条设计规则

### 2.1 领型 = 身份，占全部信息的一半

| 领型 | 身份 | 样本 |
|---|---|---|
| **立领（学ラン）** | 男学生、不良 | 03、05、13、16 |
| **水手领** | 女学生（幼→高中） | 02、18 |
| **翻领西装** | 社会人、老师、职员 | 01、04、08、10、19、22 |
| **宽驳领大衣** | 成年、有经济地位 | 09、14、15、17 |
| **圆领 / 开襟** | 日常、居家、无压力 | 12、23、24 |

**这是最省的画法**：在全身档里五官全丢，但"立领 vs 水手领 vs 西装领"这三个剪影仍然可读。领型比脸更抗压缩。

### 2.2 颈部配饰 = 身份刻度

```
无配饰（学生日常） → 细领带（社会人） → 大蝴蝶结/领巾（女学生、职业女性）
```

- 领带必带花纹：19 佩斯利、22 橙色几何。**纯色领带只给"路人"**。
- 蝴蝶结只给女性，且越大越"制服化"（10 金色大结 = 职业女性制服）。
- 围巾 = 冬季 + 成年（09 红围巾、17 红围巾），少女不用围巾。

### 2.3 军绿是绝对主色

24 件上装里 **8 件是军绿/橄榄绿**（03、05、13、16、17、19、21、22）。这是 PC-98 时代的"默认外套色"——中性、耐脏、能和肤色/黑线拉开。

配色分工：

| 位置 | 常用色 | 说明 |
|---|---|---|
| 上装 | 军绿、藏青、驼色、深红 | 低明度大块 |
| 衬衫/内搭 | 白、米白 | 提供唯一亮面 |
| 配饰 | 红、金、绿 | 1 处饱和点缀 |
| 下装 | 灰、棕、格纹 | 不与上装同色 |

**全身最多 3 个色相**：主色（上装）+ 白色（衬衫）+ 一个点缀色。

### 2.4 图案只出现在小面积

24 张里只有 7 张有图案，且**无一例外都在小面积上**：

| 图案 | 出现位置 | 样本 |
|---|---|---|
| 格纹 | 裙子、蝴蝶结 | 07、21、24 |
| 条纹 | 衬衫（细竖条） | 06 |
| 花纹 | 领带 | 19、22 |
| 文字 | T 恤胸前 | 13 |
| 缝线 | 外套横向分割 | 17 |

**上衣主体永远是纯色。** 格纹裙只在画面下 1/5，像素量最小，但辨识度最高。

### 2.5 褶皱只有两档，靠"大块暗部"

所有上装的明暗都只有 **base + 1 档暗部**（个别加 1 档高光）：

- 暗部出现在**腋下、腰侧、袖内侧**三处
- 形状是**大块楔形**，不是细碎线条
- 高光只在**肩头、袖外侧**各一条

这与 `docs/04` 的"每材质至少两档"完全一致——服装之所以在低色数下还像有体积，靠的就是这两档。

#### 管线实现（2026-11-23 分层定稿）

源图的软阴影不能直接逐像素量化，布料改为五层硬边分面，仍只使用材质已有 refs：

1. **base**：主色大面，不改变材质分类；
2. **form**：右侧真实剪影内的体积暗带，`k = 图宽 × 2%`；同一 `group` 只计算一次，领子/裙子接缝与裁切边不生横带；
3. **fold**：由腋下、收腰、扣襟、裙腰到下摆等显式锚点生成楔形或放射暗面，不再把内部褶皱一概禁止；无锚点配置时不伪造褶皱；
4. **highlight**：少量受光亮面，只在已有高光 refs 与配置同时存在时生成；
5. **occlusion**：领子、袖口、叠臂等窄投影，只落在被叠压材质一侧。

裙褶是腰点→下摆点的独立长放射路径，宽度与长度分别配置，不能退化成等距平行细线。普通 fold/form 使用同材质暗色，黑色仍只来自线稿或合法暗结构。实现见 `tools/tachie/drawing.py`，色板吸附仍由 `matregion.py` 负责。

### 2.6 冬季 = 厚度符号，不是加衣层

| 符号 | 画法 | 样本 |
|---|---|---|
| 毛领 | 白色锯齿块 + 抖动 | 09、17 |
| 宽驳领 | 领片加宽到肩 1/3 | 14、15 |
| 横向缝线 | 2–3 条水平暗线 | 17 |
| 围巾 | 红/白块，遮住颈部 | 09、17 |

**不靠增加层数**（里三层外三层会糊），靠 2–3 个符号。

### 2.7 露肤度是性格与年龄的双重指标

| 露肤 | 角色 | 读感 |
|---|---|---|
| 泳装（20） | 成熟女性 | 艳、自信 |
| 短袖 + 短裙（02、18） | 少女 | 活泼、幼 |
| 长袖衬衫卷袖（06、11） | 青年 | 随意、放松 |
| 全封闭（05、16、22） | 宅/优等生/职员 | 拘谨、规矩 |

### 2.8 三层着装模板（2026-11-23）

服装不再写进角色实例的提示词字符串，而是拆成 **原型（原型=体型+脸+发）→ 着装变体（服装+材质+绘制）→ 角色实例（spec）**。这样 24 个参考角色的服装可以跨角色复用，同一原型也能挂校服/常服两套。

| 层 | 目录 | 内容 |
|---|---|---|
| 原型 | `characters/templates/archetypes/<id>.json` | `body`（含 `bust`）、`face`、`hair`、`gender`、`age_group`、`outfit_type` |
| 着装变体 | `characters/templates/outfits/<id>.json` | `outfit` 提示词字段、`materials`、`garment_layers`、`drawing` |
| 角色实例 | `characters/<name>/spec.json` | 角色特有覆盖项；`template: {archetype, outfit}` 可显式指定 |

着装变体的最小结构：

```json
{
  "id": "female_highschool_4_sailor",
  "archetype": "female_highschool_4",
  "type": "sailor",
  "outfit": {"type": "sailor", "base": "white sailor blouse",
             "collar": "sailor collar", "accent": "green neckerchief",
             "bottom": "green pleated skirt"},
  "materials": [
    {"id": "blouse", "role": "white", "refs": ["#ffffff", "#ddddbb"]},
    {"id": "skirt", "role": "cloth", "refs": ["#668855", "#446644", "#335533"]}
  ],
  "garment_layers": [
    {"id": "blouse", "over": ["skin"]},
    {"id": "skirt", "over": ["blouse"], "occludes_below": true}
  ],
  "drawing": {
    "occlusions": [
      {"over": "skirt", "under": "blouse",
       "derive": "layer_edge", "width": 1.5, "tone": 1}
    ]
  }
}
```

规则：

- **`garment_layers.over` 只能引用 `materials` 的 id 或保留字 `skin`**；层 id 必须与材质 id 一致，`schema.validate_garment_layers` 强校验。
- **遮挡优先用 `derive: "layer_edge"`**：从 `over`/`under` 的真实接缝向 `under` 侧取带，方向由结构决定。`path` 只用于没有材质边界的装饰线；无 `derive`/`path` 时回退旧的膨胀写法（兼容存量配置）。`path` 与 `derive` 互斥。
- **胸围阴影由 `body.bust` 驱动**，不写在服装模板里：`size ≥ 2` 时在白衣的**受光背面一侧**派生一段 under-boob 月牙（厚中薄端），`size` 越大越粗越低；面积上限为白衣 2.5%。灰绿阴影不在 `pale`（`minc>200`）统计内，因此不会破坏 `white_purity ≥ 0.8`（口径见 `docs/03` §14.1）。
- **合并优先级（强制）**：`face / hair` 保留实例；`outfit / materials / drawing / garment_layers` **一律以模板为准**，实例里的旧渲染配置不得绕过模板；`body` 做深合并。
- **自动匹配**：未写 `template` 时按 `gender + outfit.type + 年龄/头身比 + 关键词` 打分，分数 → `ref` → `id` 确定性排序；结果写进 `report.json` 的 `resolved_template`。**所有渲染必须走模板**，旧实例（如 momo）必须显式声明 `template`。

### 2.9 阴影画法（新管线）

参考 `shinchou_02` 的硬边分面画法，角色阴影不再依赖源图残影，统一由 `tools/tachie/shading.py` 生成：

- **单一光向**：左上（`drawing.light = "upper-left"`），全角色共用。
- **局部尺度**：暗带宽度按连通块骨架传播出的内切半径 `R` 计算，不再使用整块材质 bbox 的比例常量；线稿/眼口等内部结构先 5×5 闭运算 + 填洞再量半径。
- **背光侧**：由距离场梯度与光向点积判定；所有暗带只落在背光侧，`deep ⊆ mid`。

| 材质 | 档位 | 阴影规则 |
|---|---|---|
| 白衣 | 3 档 `#ffffff / #adbca9 / #6d7b65` | 只用轮廓几何：背光侧 `0.58R` 中影 + `0.26R` 深影；贴脸/颈/发 3px 内保持白色；领下 `layer_edge`；胸下暗带**只画受光背面一侧**的月牙（面积上限 2.5%，中影档）；**不再使用源图亮度分位** |
| 头发 | 5 档（白高光 + 粉基 + 洋红中影 + 深红 + 深紫红） | 背光侧三档带（`0.75R / 0.30R / 0.12R`）；高光只在头部区域（发顶至眼线）与受光侧生成，源图亮部并入高光；取消发块 bbox 比例暗带与水平截断 |
| 皮肤 | 3 档 `#ffddcc / #d99a7e / #a96650` | **结构暗面**：刘海投影（沿光向下移 4px，仅头/颈）+ 每个皮肤连通块背光侧 `0.55R` 窄带 + 独立颈部顶缘投影；删除低分位带与全宽额带；脸部连通块以**膨胀后的虹膜**为锚 |
| 布料 | 3 档（基色 + 中影 + 深影） | 组级背光带两档 tone（`0.50R / 0.26R`），不再统一写最深档；`layer_edge` 先对 `over` 做 1px 腐蚀再取带，跳过蕾丝/锯齿齿尖 |

**颜色约束**：`refs` 必须能吸附到 16 色板；裙子与领子共用一条 taupe 三色阶（`#9a8a7a / #6e5f52 / #4a3f36`），靠中/深两档 tone 区分布料块，不再出现 mid 与 deep 同时塌到同一色。

**线层清理**：只清**布料内部**的短排线（<12px，8 邻域判定，邻接长线的碎片豁免）；头发上的细发丝属于参考画法的一部分，不清。

**角色区域禁止 Bayer 点阵**（`dither_density=0`）；点阵只允许出现在背景/天空。参考图的皮肤与白衣阴影都是实色块，不是网点。

**误填防护**：① 双眼锚定椭圆内、邻近皮肤的暖白像素归回皮肤（防半脸白衣阴影）；② 下半身两侧与白衣主体分离的暖白块归回皮肤（防手/前臂被填白）；③ **白衣种子之后再做一次椭圆回收**——鼻/颊高光是在面部保护之后才被 `white_seed` 染白的，必须二次归回皮肤，否则脸上会留下白色斑块；④ 下半身与主发块不相连的发色岛按邻域多数材质回收（防裙影/大腿被分类成头发）；⑤ 被头发包围的白点归回头发并作为高光上色。

命令与校验：

```
python tools/tachie/pipeline.py --spec characters/xxx/spec.json --source <源图> \
       --out xxx --palette output/palettes/xxx.json --tier half
python -m unittest discover -s tools/common -p "test_template.py"
python -m unittest discover -s tools/tachie -p "test_body_shading.py"
```

新增模板必须同时补 `characters/templates/index.json`（`archetypes[].outfits` 与 `outfits[]` 双向登记），否则 `schema.load_template` 会以“未登记到 index”拒绝。

## 3 像素画法（可直接落地）

| 部件 | 画法 | 像素量 |
|---|---|---|
| 轮廓 | 1px 纯黑 | 必画 |
| 大色块 | 纯色填充 | 主面积 |
| 暗部 | 同色相深 1 档，楔形块 | 2–3 块 |
| 高光 | 同色相亮 1 档，肩/袖各 1 条 | 1–2 条 |
| 纽扣 | 1px 亮 + 1px 黑 | 每扣 2px |
| 领口滚边 | 1px 白/亮色 | 立领专用 |
| 格纹 | 2 色交错，2×2 周期 | 只用于裙/结 |
| 毛领 | 白 + 深灰锯齿，2px 高 | 领口一圈 |

**禁止**：细密褶皱线（<3px 的密集短线）、渐变、多层衣物叠画。

## 4 与三档管线的对接

| 特征 | 特写 | 半身 | 全身 |
|---|---|---|---|
| 领型 | ✅ 完整 | ✅ 完整 | ✅ **唯一可靠的识别点** |
| 领带/蝴蝶结 | ✅ | ✅ | ⚠️ 只剩色块 |
| 纽扣 | ✅ | ✅ | ❌ |
| 格纹 | ✅ | ✅ 2×2 | ❌ 退化为纯色 |
| 褶皱暗部 | ✅ | ✅ | ✅ 大块 |
| 毛领/缝线 | ✅ | ⚠️ 需简化 | ❌ |

结论：
1. **全身档的服装必须靠"领型 + 主色"两个信息**，其余全部丢弃。所以全身档角色的差异化要放在这两项上。
2. 半身档是"格纹 + 纽扣 + 配饰"的最后一档，再小就退化成色块。
3. 服装的分档比五官宽松——五官在全身档全失效，服装还能留住领型。
