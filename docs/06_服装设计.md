## 2 七条设计规则

### 2.1 领型 = 身份，占全部信息的一半

| 领型 | 身份 | 样本 |
|---|---|---|
| **立领（学ラン）** | 男学生、不良 | 03、05、13、16 |
| **水手领** | 女学生（幼→高中） | 02、18 |
| **翻领西装** | 社会人、老师、职员 | 01、04、08、10、19、22 |
| **宽驳领大衣** | 成年、有经济地位 | 09、14、15、17 |
| **圆领 / 开襟** | 日常、居家、无压力 | 12、23、24 |

**这是最省的画法**：在全身档里五官全丢，但"立领 vs 水手领 vs 西装领"这三个剪影仍然可读。领型比脸更抗压缩。

### 2.2 颈部配饰 = 身份刻度

```
无配饰（学生日常） → 细领带（社会人） → 大蝴蝶结/领巾（女学生、职业女性）
```

- 领带必带花纹：19 佩斯利、22 橙色几何。**纯色领带只给"路人"**。
- 蝴蝶结只给女性，且越大越"制服化"（10 金色大结 = 职业女性制服）。
- 围巾 = 冬季 + 成年（09 红围巾、17 红围巾），少女不用围巾。

### 2.3 军绿是绝对主色

24 件上装里 **8 件是军绿/橄榄绿**（03、05、13、16、17、19、21、22）。这是 PC-98 时代的"默认外套色"——中性、耐脏、能和肤色/黑线拉开。

配色分工：

| 位置 | 常用色 | 说明 |
|---|---|---|
| 上装 | 军绿、藏青、驼色、深红 | 低明度大块 |
| 衬衫/内搭 | 白、米白 | 提供唯一亮面 |
| 配饰 | 红、金、绿 | 1 处饱和点缀 |
| 下装 | 灰、棕、格纹 | 不与上装同色 |

**全身最多 3 个色相**：主色（上装）+ 白色（衬衫）+ 一个点缀色。

### 2.4 图案只出现在小面积

24 张里只有 7 张有图案，且**无一例外都在小面积上**：

| 图案 | 出现位置 | 样本 |
|---|---|---|
| 格纹 | 裙子、蝴蝶结 | 07、21、24 |
| 条纹 | 衬衫（细竖条） | 06 |
| 花纹 | 领带 | 19、22 |
| 文字 | T 恤胸前 | 13 |
| 缝线 | 外套横向分割 | 17 |

**上衣主体永远是纯色。** 格纹裙只在画面下 1/5，像素量最小，但辨识度最高。

### 2.5 褶皱只有两档，靠"大块暗部"

所有上装的明暗都只有 **base + 1 档暗部**（个别加 1 档高光）：

- 暗部出现在**腋下、腰侧、袖内侧**三处
- 形状是**大块楔形**，不是细碎线条
- 高光只在**肩头、袖外侧**各一条

这与 `docs/04` 的"每材质至少两档"完全一致——服装之所以在低色数下还像有体积，靠的就是这两档。

#### 管线实现（2026-11-23 分层定稿）

源图的软阴影不能直接逐像素量化，布料改为五层硬边分面，仍只使用材质已有 refs：

1. **base**：主色大面，不改变材质分类；
2. **form**：右侧真实剪影内的体积暗带，`k = 图宽 × 2%`；同一 `group` 只计算一次，领子/裙子接缝与裁切边不生横带；
3. **fold**：由腋下、收腰、扣襟、裙腰到下摆等显式锚点生成楔形或放射暗面，不再把内部褶皱一概禁止；无锚点配置时不伪造褶皱；
4. **highlight**：少量受光亮面，只在已有高光 refs 与配置同时存在时生成；
5. **occlusion**：领子、袖口、叠臂等窄投影，只落在被叠压材质一侧。

裙褶是腰点→下摆点的独立长放射路径，宽度与长度分别配置，不能退化成等距平行细线。普通 fold/form 使用同材质暗色，黑色仍只来自线稿或合法暗结构。实现见 `tools/tachie/drawing.py`，色板吸附仍由 `matregion.py` 负责。

### 2.6 冬季 = 厚度符号，不是加衣层

| 符号 | 画法 | 样本 |
|---|---|---|
| 毛领 | 白色锯齿块 + 抖动 | 09、17 |
| 宽驳领 | 领片加宽到肩 1/3 | 14、15 |
| 横向缝线 | 2–3 条水平暗线 | 17 |
| 围巾 | 红/白块，遮住颈部 | 09、17 |

**不靠增加层数**（里三层外三层会糊），靠 2–3 个符号。

### 2.7 露肤度是性格与年龄的双重指标

| 露肤 | 角色 | 读感 |
|---|---|---|
| 泳装（20） | 成熟女性 | 艳、自信 |
| 短袖 + 短裙（02、18） | 少女 | 活泼、幼 |
| 长袖衬衫卷袖（06、11） | 青年 | 随意、放松 |
| 全封闭（05、16、22） | 宅/优等生/职员 | 拘谨、规矩 |

## 3 像素画法（可直接落地）

| 部件 | 画法 | 像素量 |
|---|---|---|
| 轮廓 | 1px 纯黑 | 必画 |
| 大色块 | 纯色填充 | 主面积 |
| 暗部 | 同色相深 1 档，楔形块 | 2–3 块 |
| 高光 | 同色相亮 1 档，肩/袖各 1 条 | 1–2 条 |
| 纽扣 | 1px 亮 + 1px 黑 | 每扣 2px |
| 领口滚边 | 1px 白/亮色 | 立领专用 |
| 格纹 | 2 色交错，2×2 周期 | 只用于裙/结 |
| 毛领 | 白 + 深灰锯齿，2px 高 | 领口一圈 |

**禁止**：细密褶皱线（<3px 的密集短线）、渐变、多层衣物叠画。

## 4 与三档管线的对接

| 特征 | 特写 | 半身 | 全身 |
|---|---|---|---|
| 领型 | ✅ 完整 | ✅ 完整 | ✅ **唯一可靠的识别点** |
| 领带/蝴蝶结 | ✅ | ✅ | ⚠️ 只剩色块 |
| 纽扣 | ✅ | ✅ | ❌ |
| 格纹 | ✅ | ✅ 2×2 | ❌ 退化为纯色 |
| 褶皱暗部 | ✅ | ✅ | ✅ 大块 |
| 毛领/缝线 | ✅ | ⚠️ 需简化 | ❌ |

结论：
1. **全身档的服装必须靠"领型 + 主色"两个信息**，其余全部丢弃。所以全身档角色的差异化要放在这两项上。
2. 半身档是"格纹 + 纽扣 + 配饰"的最后一档，再小就退化成色块。
3. 服装的分档比五官宽松——五官在全身档全失效，服装还能留住领型。
