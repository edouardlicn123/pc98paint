# 09 材质系统与人设配置（devdoc）

2026-11-22。目标：每个角色一份配置；材质由配置驱动，不再写死"藏青制服 + 棕发"。

## 1. 命名规则

- `characters/<角色名>/spec.json`，目录名与 `id` 都是角色名，**不用 v2/v3**；
- 改设定直接改当前 spec，版本交给 git；
- 产出 `<角色>_<档位>_<表情>.png`；参考图 `refs/characters/<角色>/`；源图 `_work/pc98_src/<角色>/`。

暂定：`akira`、`shiori`（眼镜抱书）、`momo`（粉发长卷）。名字可随时改，只影响目录。

## 2. spec 的 materials

```json
"materials": [
  { "id": "skin",   "role": "skin",   "refs": ["#f6d9c8", "#e8b39c", "#b57a6a"], "paint": "bands3" },
  { "id": "hair",   "role": "hair",   "refs": ["#f7b8a8", "#f19a86", "#8f4a52"], "paint": "hair_ring" },
  { "id": "blouse", "role": "white",  "refs": ["#ffffff", "#dcd3c6"],             "paint": "white" },
  { "id": "collar", "role": "cloth",  "refs": ["#8f7f70", "#6e5f52"],             "paint": "rim" },
  { "id": "skirt",  "role": "cloth",  "refs": ["#8f7f70", "#4a3f36"],             "paint": "rim" },
  { "id": "bow",    "role": "accent", "refs": ["#e8b73a", "#a87a1e"],             "paint": "flat2" },
  { "id": "iris",   "role": "eye",    "refs": ["#2f8f86"],                        "paint": "flat" }
]
```

- `refs` 从三视图实测，亮→暗；头发必须有第 1 个高光色；
- 同一角色可有任意多个材质，领子/袖子/裙子可分开；
- `role` 决定绘制规则，`paint` 可在默认上覆盖。

## 3. 分类

按 Lab 最近参考色族分类，并加先验：

1. 暗结构（亮度 < 0.16）→ 线/瞳孔，不参与材质；
2. 白色种子（低饱和高亮）→ 白色材质；
3. 头发先验：连到人物顶部；
4. 次优与最优 ΔE 相差 < 20% 时用空间先验裁决；
5. < 12px 碎块并入邻域多数。

无 `materials` 的旧 spec 走原逻辑，行为不变。

## 4. 绘制规则

| role | 规则 |
|---|---|
| white | 纯白 + 单阴影；仅 ≥200px 大块分带，小高光保持纯白 |
| skin | 2–3 档，材质中位数分带 |
| cloth | base + 组级轮廓 form；配置锚点后增加 fold/highlight/occlusion，裁切边不算轮廓 |
| hair | 三带反光：高光带在顶轮廓内 22–33% 发高，暗带在下沿/内侧/刘海下，硬边 |
| accent | 两档平涂，不做轮廓暗带 |
| eye | 单色虹膜 + 纯白高光，不分带 |

头发高光带允许断成 2–3 段（卷发），每段 ≥20px，禁止散点。

### 4.1 线稿与布料分层

`tools/tachie/drawing.py` 统一提供三类互斥线稿：`outline` 外轮廓、`structure` 内部结构、`strands` 发丝。三类候选只细化一次，按八邻域去噪；剪影与材质接缝受保护，白衣宽阔内部的无暗芯灰影不转黑线。

白衣与布料使用五层掩码：base、form、fold、occlusion、highlight。`spec.drawing.folds[]` 用所属材质 bbox 的 0–1 坐标配置 `from/to` 或 `path`，`tone` 是该材质既有 refs 的整数索引；`occlusions[]` 用 `over/under` 限定投影归属。没有配置时只画 base + form，不自动补褶。

`spec.drawing.materials.<id>.surface` 支持 plain、plaid、fur、swimwear：格纹随 fold 位移场弯折，毛绒只在边缘生成确定性锯齿，泳装沿配置弧线和源图亮脊加高光。全部颜色仍吸附既有 16 色板。

调试命令：`python tools/tachie/pipeline.py --spec <spec> --source <源图> --out <名称> --palette <色板> --tier half --drawing-debug`。分层图与报告写 `_work/scratch/<名称>_drawing/`，正式输出不变。

## 5. 色板

`tools/common/palette_for.py --spec <spec> --out output/palettes/<角色>.json`

- 12 核心槽固定，4 个弹性槽按 spec 参考色自动选；
- 目标：所有材质到最近槽的 ΔE 之和最小；
- 输出记录 `materials → slot` 映射。

## 6. 验收

- `materials_report.json`：每材质像素数、槽位、分带数；
- 白衣区皮肤像素 = 0；cloth 的黑色只能来自线稿/合法闭塞；hair 高光带 2–3 段；
- 配置 fold 必须命中锚点且实际生成，五层不得越出 white/cloth 材质；
- `--drawing-debug` 导出三类线、五类布料与材质图，先看分层再验收成品。
