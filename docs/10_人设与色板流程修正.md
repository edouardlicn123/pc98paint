# 10 人设、色板与材质流程修正（devdoc）

2026-11-22。记录 momo 这一轮暴露的流程问题与修正方案。**本文件是待评审稿，除已标注"已执行"的条目外均未实施。**

## 1. 现象

| # | 现象 | 证据 |
|---|---|---|
| 1 | 三视图没有被使用 | spec 写在三视图之前，颜色是手填 hex；半身源图另行文字生成 |
| 2 | 领子、裙子变成绿色 | 16 色里没有灰褐槽，taupe 吸附到 `gray_green_dark` |
| 3 | 头发头顶粉、两侧棕 | 粉发需要三档，色板只有 `blush` 一个粉槽，基色落到 `brown` |
| 4 | 脸颊出现红棕块 | 皮肤最深参考色 `#b57a6a` 吸附到 `brown`/`red_dark`；雀斑并入皮肤后放大成色斑 |
| 5 | 裙子上有条状污迹 | 裙子被拆成 `collar` 11597px 与 `skirt` 849px，两块各算一次右侧暗带，接缝处形成横带 |
| 6 | 文件名仍是 `girl_v3_*` | 改名只改了目录和 spec 的 id，源图与旧产出未改 |

## 2. 根因

### 2.1 顺序错误

正确顺序是"三视图 → 采样 → spec → 立绘"，实际做成了"提示词 → 手写 spec → 三视图 → 另生成立绘"。三视图因此只是一张展示图，没有参与任何定义。

### 2.2 色板定位错误

把色板当成渲染阶段的产物（全局 12 核心 + 4 弹性槽），而不是角色属性。这个设计适合"所有角色共用一套色"的假设，但实际工作是一次一个角色，色板必须按角色配。

### 2.3 材质粒度与阴影粒度不一致

`materials` 按颜色分（领子、裙子、袖口），而 `_rim_shadow` 按材质分别计算。同一件衣服被拆开后，每块都在自己的轮廓内侧长暗带，接缝处就是"污迹"。

### 2.4 皮肤没有独立色族

皮肤用"最近参考色"取色，参考色一旦吸附到跨族槽（棕、酒红），阴影就会变色；雀斑这类高饱和小面积也没有降级规则。

## 3. 修正原则

1. **三视图是唯一人设来源**。spec 里的所有颜色必须从三视图采样，不允许手填。
2. **色板是角色属性**。创建角色时定稿，存 `characters/<角色>/palette.json`，渲染原样使用。
3. **16 色总数不变，但不再强制 12 核心色**。按该角色的材质覆盖度选 16 槽，黑色与白色强制保留。
4. **阴影按衣物组计算**。`materials` 增加 `group` 字段，同组先合成一个 mask 算一次暗带，再按像素材质上色。
5. **皮肤独立色族**。皮肤只允许皮肤槽；半身及以下档位的雀斑/腮红并入中间调，不单独出块。
6. **文件命名以角色名为准**，从生成那一刻起就用角色名。

## 4. 修正后的流程

```
1 三视图（人设图，白底、三视角、全身）
2 从三视图采样材质色
3 写 spec + 配 16 色板 → 人工评审
4 按同一人设生成半身源图（平视、无表情）
5 用该角色色板渲染
6 验收（见第 7 节）
```

角色目录：

```
characters/<角色>/
├─ spec.json       人设与 materials
├─ palette.json    16 色（定稿）
└─ refs/           三视图、头/身拆分
```

## 5. 配置格式

`spec.materials` 增加 `group`：

```json
{ "id": "collar", "role": "cloth", "group": "uniform",
  "refs": ["#9a8a7a", "#6e5f52"] },
{ "id": "skirt",  "role": "cloth", "group": "uniform",
  "refs": ["#8f7f70", "#4a3f36"] }
```

- `group` 只影响阴影范围，不影响分类；
- 没有 `group` 的材质各自成组，行为与现在一致。

`palette.json`：

```json
{
  "character": "momo",
  "colors": [[0,0,0], [255,255,255], "..."],
  "roles": { "skin": [...], "hair": [...], "cloth": [...],
             "white": [...], "accent": [...], "eye": [...] }
}
```

`roles` 用于校验：每个角色至少覆盖 skin / hair / white / cloth 四类。

## 6. 绘制规则（本轮新增/修改）

| 项 | 旧 | 新 |
|---|---|---|
| 色板 | 12 核心 + 4 弹性 | 16 槽按角色覆盖度选，黑白必留 |
| 布料阴影 | 每材质各算 | 按 `group` 合成后算一次 |
| 皮肤 | 最近参考色 | 皮肤族内三档，禁止跨族吸附 |
| 雀斑/腮红 | 参与分类 | 特写保留，半身及以下并入中间调 |
| 头发 | 亮度分位 | 三带反光（已实现） |

## 7. 验收

1. 三视图存在且被采样：spec 中每个 ref 可追溯到图中位置；
2. 色板 16 色，角色四类材质全覆盖；
3. 皮肤阴影不出现棕/酒红；
4. 同一衣物组内无横向暗带；
5. 头发高光带 2–3 段，基色与参考色同族；
6. 白衣区无肤色，布料区无纯黑；
7. lint 六项 PASS。

## 10. 执行记录（2026-11-22）

- **色板**：`palette_for.py` 改为"材质参考色优先"：先把每个 ref 量化为 4bit 槽，黑白强制保留；超过 16 色时先合并同 role 同 group 的主色（本轮合并了 collar/skirt 的基色），不足再从 CORE/FLEX 补齐。momo 的 16 槽现在包含皮肤三档 `#eeddcc / #eebb99 / #bb7766`、头发三档、布料基色与阴影、蝴蝶结与虹膜。
- **皮肤**：`matregion.py` 以受光色为基色，阴影只取右轮廓暗带 + 确实偏暗的区域（下巴/发下），小碎块并回基色，避免逐像素分位在脸上切出碎斑。
- **眼睛**：新增虹膜护栏——以暗虹膜为种子，把周围青绿（高光边缘）归回 eye 材质，把眼圈内的小亮块归回白色，避免亮虹膜被皮肤抢走。
- **脸部纯白修正**：白色种子不再覆盖已被参考色识别为皮肤的像素；对误分为白衣的小块，只有被既有皮肤包围且排除白色后最近的是皮肤时才回收，避免反过来把白衣判成皮肤。眼白仍由眼部规则归白。
- **本轮产出**：`output/momo_neutral_half_half.png`（257×360，16 色），lint 六项 PASS，材质统计 `skin 4223 / hair 23184 / blouse 16877 / collar 11600 / skirt 855 / bow 2521 / iris 238`。下巴与嘴周纯白块已消除，脸部除眼白外无大块纯白。
- **待人工确认**：肤色基色偏浅（来自三视图采样）、右颊阴影是否保留；眼睛高光形态是否接受。
