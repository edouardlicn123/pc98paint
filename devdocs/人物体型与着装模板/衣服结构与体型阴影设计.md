# 衣服结构与体型阴影设计

> 配套文档：[spec.md](./spec.md)（需求与验收）、[tasks.md](./tasks.md)（实现计划）。本文展开 spec 中 FR-2/FR-4/FR-8/FR-9 的**详细设计**：衣服之间的层叠遮挡关系，以及衣服阴影如何随体型（胸围、躯干倾斜）变化。

## 1. 背景与要解决的问题

上一阶段已实现 `ClothLayers` 五层（base / form / fold / occlusion / highlight），但存在两个根因问题：

1. **`form` 暗带与体型无关**：`drawing.rim_shadow` 固定取每个材质掩码的右半侧（`xx >= xs.mean()`），宽度 `k = 宽 × 2%`。它只表达"右侧背光"，不表达胸部体积、躯干扭转——所以 momo 配置前后仅 699px 变化，肉眼几乎无差异。
2. **`occlusion` 手填坐标错位**：`drawing.occlusions` 用归一化 `path` 猜领影位置，结果落在领 V 字中间而非领下沿（见 `_work/scratch/collar_occ.jpg`）。换角色/姿势必错，因为坐标不是从衣物真实边界派生的。

本设计的目标：
- 用 **`garment_layers` 声明衣衣层叠关系**（谁压谁），再用 **`derive: layer_edge` 从材质真实边界派生遮挡阴影**——替换手填坐标。
- 用 **`body.bust` 驱动白衣胸部阴影**（under-boob 弧），让大胸/平胸的衣物阴影可区分——替换与体型无关的固定 `form`。

## 2. 设计总览：三层逻辑

```
声明层（模板数据）              派生层（算法）                  消费层（上色）
─────────────────              ──────────────                ──────────────
garment_layers          ──►    derive: layer_edge      ──►   occlusion 层
 (over/under/                    (取 over/under 真实            (最暗，最后盖)
  occludes_below)                 边界，向 under 膨胀)
                                  │
body.bust / torso.lean   ──►    under-boob 弧            ──►   form / occlusion 层
 (size/center_y/                  (size≥2 触发，位置由             (胸部体积阴影)
  separation/lean)                bust 几何决定)
```

数据流（body 透传，**T5/T8 实现时新增**）：

```
pipeline.main:
  effective = resolve_template(spec)          # 原型→着装变体→实例合并
  prompt.build(effective)                     # 体型 token 参数化
  asset3.render(..., body=effective.get("body"),
                drawing_config=effective.get("drawing"))
        │
asset3.render:
  matregion.render_spec(rgb, fg, pal, materials, tier,
                        drawing_config=drawing_config, body=body)
        │
matregion.render_spec:
  drawing.build_cloth_layers(rgb, fg, idx, materials,
                             drawing_config, body=body)   # ← 新增 body 参数
```

> 现状：`build_cloth_layers(rgb, fg, material_idx, materials, config=None)` 没有 `body`。`asset3.render` / `matregion.render_spec` 也没有。这是 T8 的改动点，签名向后兼容（`body=None` 默认关闭体型阴影，保证 momo 回归）。

## 3. garment_layers：衣服之间的层叠关系

### 3.1 字段定义

在**着装变体模板**（`characters/templates/outfits/<id>.json`）里声明：

```jsonc
"garment_layers": [
  { "id": "undershirt", "over": ["skin"] },
  { "id": "collar",      "over": ["undershirt"] },
  { "id": "skirt",       "over": ["undershirt"], "occludes_below": true }
]
```

| 字段 | 含义 | 说明 |
|---|---|---|
| `id` | 层 id | **必须等于** `materials[].id`，建立结构声明↔材质掩码的对应 |
| `over` | 该层压在哪些层之上 | 数组，引用其它 `garment_layers[].id`；`skin` 是保留字（皮肤） |
| `occludes_below` | 是否在层下沿产生对下层的遮挡带 | 布尔，默认 false；裙子腰头、下摆、领下沿用 true |

层叠顺序由 `over` 关系的拓扑序决定：`skin`（最底）→ `undershirt` → `collar` / `skirt`（最外）。

### 3.2 典型遮挡链：上衣 ↔ 裙子

以水手服为例（`garment_layers` 如上），派生的遮挡对：

| over（压住方） | under（被压方） | 阴影含义 | 触发方式 |
|---|---|---|---|
| `collar` | `undershirt` | 领下沿在白衬衫上的投影 | `derive: layer_edge`，沿 collar/undershirt 真实边界 |
| `skirt` | `undershirt` | 裙子腰头压住衬衫下摆的投影 | `derive: layer_edge`，沿 skirt/undershirt 边界 |
| `undershirt` | `skin` | 衬衫领口/袖口对皮肤的遮挡 | `derive: layer_edge` |

**关键点**：阴影不再写死坐标，而是**从 `material_idx` 里 over/under 两材质的真实接缝派生**。角色换姿势、换体型，材质边界跟着变，阴影自动贴合。

### 3.3 与现有 `drawing.occlusions` 的关系

- `garment_layers` 是**结构声明**（谁压谁），不直接画阴影。
- `drawing.occlusions` 是**绘制配置**（画哪条、多宽、用哪个色阶）。每条 occlusion 通过 `over`/`under` 引用 `garment_layers`/`materials` 的 id，再选 `derive` 模式：
  - `derive: "layer_edge"`（**新，推荐**）：从真实边界派生，见 §4。
  - `path: [[x,y],...]`（旧，保留）：手填归一化折线，用于 layer_edge 覆盖不到的特殊褶皱；momo 现有配置继续走此分支，保证回归。

`schema.py` 校验：一条 occlusion **不能同时**给 `path` 和 `derive`（T4）。

## 4. derive: layer_edge —— 结构派生遮挡

### 4.1 算法

输入：`material_idx`（每像素材质 id）、`over`/`under` 材质 id、`width`。

```
1. boundary = _material_boundaries(material_idx)   # 已有函数，求所有材质接缝
2. seam = boundary  &  (over_mask 的 4 邻域膨胀)  &  under_mask
   # 即：under 侧、贴着 over/under 接缝的像素
3. dist = distance_transform_edt(over_mask)        # under 内每像素到 over 的最近距离
4. band = under_mask  &  (dist <= width)           # 向 under 内部膨胀 width
5. band = _clean_area(band)                        # 已有函数，去 <2px 孤岛
6. 写入 occlusion 层，tone = cfg.tone（under 材质的 refs 索引）
```

> `_material_boundaries`（drawing.py 现有）和 `distance_transform_edt`（scipy，已在用）都已存在，无需新依赖。

### 4.2 为什么比手填 path 准

- 手填 path：`[[0.326, 0.433], ...]` 是相对**整个画布**的归一化坐标，与材质实际位置无关 → 领影飘到 V 字中间。
- layer_edge：坐标来自 `material_idx` 的真实接缝 → 领影永远贴在领子的真实下沿。

### 4.3 验证（对应 AC-7 / TR-7.1）

构造左右相邻的 over/under 合成掩码（左半 over、右半 under），配 `derive=layer_edge, width=2`：
- 阴影像素必须**全部落在 under 内**（不越界到 over）；
- 每个阴影像素到 over/under 边界的距离 ≤ `width + 1`（不飘离到材质中部）。

## 5. 体型驱动衣物阴影：bust → under-boob 弧

### 5.1 bust 字段（来自原型模板，经 T1 测量校准）

```jsonc
"bust": {
  "size": 2,              // 0=平胸/男性, 1=小, 2=中, 3=大, 4=丰满
  "center_y_head": 1.90,  // 胸高点距头顶的头高倍数（1.0=颈线）
  "separation": 0.42,     // 两胸间距 / 白衣 bbox 宽度（0–1 归一化）
  "under_boob_y_head": 2.20, // 下胸围线距头顶的头高倍数（size=0 时 null）
  "projection": 0.0       // 侧面突起度（半身正视图影响小，预留）
}
```

`torso.lean`：躯干左右倾斜，`-0.5 ~ 0.5`，正=向右倾。

### 5.2 归一化坐标 → 白衣材质 bbox 的映射

bust 的 `*_head` 是"距头顶的头高倍数"（`1.0` = 颈线），需要映射到白衣（`role=white`，如 blouse/undershirt）材质掩码的像素坐标。复用现有 `_points` 的 bbox 归一化体系（drawing.py）：

```
白衣 bbox = _bbox(white_mask) → (x0, y0, x1, y1),  H = y1 - y0,  W = x1 - x0

锚点头高（archetype.body 提供，由测量给出）：
  neck_y_head  = 1.0   # 颈线 ≈ 头顶下 1 头高，对应白衣 bbox 顶部 y0
  waist_y_head = 3.5   # 腰 ≈ 头顶下 3.5 头高，对应白衣 bbox 底部 y1

映射：
  y_norm = (bust.center_y_head - neck_y_head) / (waist_y_head - neck_y_head)
  arc_y  = y0 + clamp(y_norm, 0, 1) * H
  center_x_norm = 0.5 + torso.lean * 0.3      # 躯干倾斜 → 弧心水平偏移
  half_sep_px   = bust.separation * W * 0.5   # 两胸半距（像素）
```

> `neck_y_head` / `waist_y_head` 是初值，T1 测量时用实测分布校准后冻结在 `bust_analysis.md`。若白衣 bbox 与躯干锚点偏差大，回退到"白衣 bbox 内相对位置"（y0→领口，y1→下摆），不硬依赖头高。

### 5.3 under-boob 弧生成

当 `bust.size >= 2` 时，在白衣材质上派生一条**向下凸的弧**（∪ 形，位于下胸围线）：

```
控制点（归一化到白衣 bbox，已映射到像素）：
  left   = (center_x - half_sep_px, arc_y - 0.05*H)
  bottom = (center_x,               arc_y + 0.08*H)   # 弧底向下
  right  = (center_x + half_sep_px, arc_y - 0.05*H)

# 三点二次贝塞尔重采样为 9 点，避免直线段形成生硬 V 形
curve   = bezier(left, bottom, right, t=0..1, steps=9)
stroke  = _stroke(shape, curve, width=arc_width, kind="arc")
band    = stroke & white_mask
band    = _clean_area(band)
写入 occlusion 层，tone = 白衣 refs 的最暗档
```

弧参数（2026-11-23 校准）：

| bust.size | 触发 | 弧宽 `arc_width` | 视觉效果 |
|---|---|---|---|
| 0 | 否 | — | 无胸部暗化（平胸/男性） |
| 1 | 否 | — | 胸部不单独加弧 |
| 2 | 是 | 2.4px | 轻微下胸弧 |
| 3 | 是 | 3.1px | 明显下胸弧 |
| 4 | 是 | 3.8px | 丰满，弧更宽更低 |

`arc_width = 1.0 + size * 0.7`（size≥2 时）。**面积上限**：弧像素超过白衣面积的 1.2% 时按
`sqrt(target/current)` 回缩线宽并重绘一次，保证 `white_purity ≥ 0.8` 不被击穿。
`under_boob_y_head` 与 `projection` 当前只记录不参与绘制，弧的位置由 `center_y_head` 决定。

### 5.4 torso.lean 的影响

`center_x_norm = 0.5 + torso.lean * 0.3`：躯干向右倾（lean>0）→ 弧心右移 → under-boob 弧整体右偏，符合扭转时胸部体积的视觉位移。

验证（对应 TR-8.2）：`torso.lean` 从 0 → 0.3，弧的水平质心位移 > 0 且方向与 lean 一致。

### 5.5 与既有 form 暗带的关系

- 既有 `form`（`rim_shadow` 右半侧暗带）**保留**，负责整体右侧背光。
- under-boob 弧**叠加**在 `form` 之上（写入 occlusion 或单独 bust_form 通道），负责胸部体积。
- `size == 0` 时不产生弧，平胸/男性的白衣阴影只有 `form` 右带 → 与现状一致 → 回归安全。

## 6. 布料层上色优先级（消费侧，matregion）

`matregion.render_spec` 的 `apply_layer` 顺序（现有，matregion.py:515-525）：

```
base(材质基色) → form(体积暗面) → surface(图案) → fold(褶皱) → highlight(高光) → occlusion(遮挡)
```

`occlusion` 在**最上层最后盖**，符合"被压住的地方最暗"。bust 弧若写入 occlusion 层，会盖在 form/fold 之上，视觉上是胸下最深的一道线——正确。

`protected` 掩码包含所有 cloth 层（`fold | occlusion | highlight | surface`），去噪时不会被吞掉（matregion.py:539）。

## 7. 配置示例

一个着装变体（女高中生·水手服）的相关片段：

```jsonc

  "id": "female_highschool_1_sailor",
  "archetype": "female_highschool_1",
  "garment_layers": [
    { "id": "undershirt", "over": ["skin"] },
    { "id": "collar",      "over": ["undershirt"] },
    { "id": "skirt",       "over": ["undershirt"], "occludes_below": true }
  ],
  "materials": [
    { "id": "undershirt", "role": "white", "refs": ["#ffffff", "#dcd3c6"], "paint": "white" },
    { "id": "collar",     "role": "cloth", "refs": ["#9a8a7a", "#6e5f52"], "paint": "rim" },
    { "id": "skirt",      "role": "cloth", "refs": ["#8f7f70", "#4a3f36"], "paint": "rim" }
  ],
  "drawing": {
    "light": "upper-left",
    "materials": {
      "undershirt": { "surface": "plain" },
      "collar":     { "surface": "plain" },
      "skirt":      { "surface": "plain" }

      { "over": "collar", "under": "undershirt", "derive": "layer_edge", "width": 2.5, "tone": 1 },
```

```jsonc
  "bust": { "size": 2, "center_y_head": 1.90, "separation": 0.42,
```

## 9. 验证方式

1. **单元**（T9）：layer_edge 像素带贴边界（TR-7.1）；bust size 0 vs 3 像素差（TR-8.1）；torso.lean 质心偏移（TR-8.2）；模板合并/自动选择（TR-5.x）。
2. **回归**（T10）：momo 不传 body（或 body 不触发弧）→ 渲染与基线像素差在容差内（TR-10.1）。
3. **目视**（T10，rubric）：
   - AC-11：`cloth_occlusion.png` 叠加 `material_idx.png`，领影/裙腰影是否贴真实边界。
   - AC-13：大胸例（成熟女性1/人妻职业女性）vs 平胸例（萝莉/男高中生）渲染对比，大胸有 under-boob 弧、平胸无。

## 10. 不在本阶段范围

- 侧面/扭转角度的完整 3D 体积建模（半身正视图只做 torso.lean 一级近似）。
- 改 `material_idx` 分类、色板、量化（硬约束，见 spec Constraints）。
