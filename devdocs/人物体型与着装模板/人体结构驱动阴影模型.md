# 人体结构驱动阴影模型

> **状态**：理论定稿；v17 连续结构阴影管线已落地（2026-11-24），待后续视觉迭代
>
> **来源**：知乎专栏 <https://zhuanlan.zhihu.com/p/340627232> + 用户标注参考图（大沢ひな子/山本のり子/井之上貴久美）+ 定量测量
>
> **核心命题**：**阴影不是衣服的皱褶，是人体结构的描绘。** 衣服是覆盖在人体上的薄壳，衣服阴影 = 人体阴影。

---

## 一、核心原则

### 1.1 阴影的目的

阴影的唯一目的是**描绘形体结构**——让观众看出人体的三维形状。它不是装饰，不是皱褶，不是衣服自己的形状。

### 1.2 人体是连续曲面

人体**不是**各部位的拼接，而是**一个连续的三维曲面**：

```
        头（球）
         │
        颈（圆柱）
         │
    ┌────┴────┐
    │  胸（半球） │  ← 凸起
    │    ↓     │
    │  腰（圆柱） │  ← 内凹
    │    ↓     │
    │  骨盆（球） │  ← 凸起
    └────┬────┘
         │
    手臂（圆柱）← 与躯干连续
```

**所有阴影都是连续的**，因为人体本身就是连续的。

### 1.3 衣服是薄壳

衣服覆盖在人体曲面上，不改变人体的基本形状。因此：
- **衣服阴影 = 人体阴影**
- 衣服的 silhouette 只是阴影的**载体**，不是阴影的**来源**
- 阴影的形状由**人体结构**决定，不由衣服轮廓决定

## 二、人体结构模型

### 2.1 躯干分区

| 部位 | 几何体 | 形状特征 | 阴影特征 |
|---|---|---|---|
| 胸部 | 两个半球 | 向外、向前突出 | 背光侧月牙 + 下方投射阴影 |
| 腰部 | 圆柱 | 内凹 | 背光侧渐变带 |
| 骨盆 | 球 | 向外突出 | 背光侧月牙 |
| 胸→腰 | 连续过渡 | 半球→圆柱 | **阴影连续，无分界** |

### 2.2 四肢分区

| 部位 | 几何体 | 阴影特征 |
|---|---|---|
| 上臂 | 圆柱 | 背光侧暗带 |
| 前臂 | 圆柱 | 背光侧暗带 + 衣袖遮挡阴影 |
| 大腿 | 圆柱 | 背光侧暗带 |
| 小腿 | 圆柱 | 背光侧暗带 |

### 2.3 连续性规则

**胸部阴影和腰部阴影是一个整体**，服务对象是身体曲线的描绘：

- 胸部背光面 → 腰部背光面：**连续过渡**
- 胸部下方投射阴影 → 腰部背光面：**连续过渡**
- 躯干背光面 → 手臂背光面：**连续过渡**
- 衣袖背光面 → 手臂背光面：**连续过渡** + **遮挡阴影**

**不存在独立的"胸部阴影"、"腰部阴影"、"衣袖阴影"**——它们都是同一个连续背光面的不同部分。

### 3.3 通用定位规则

```
# 正面直立
胸部中心 Y = 肩线 + 躯干长度 × 0.57   # 范围 52–62%

# 前倾
胸部中心 Y = 肩线 + 躯干长度 × 0.76   # 前倾使胸部投影更低

# 通用头身锚点
胸部中心 Y = 头顶 + 头高 × 2.4        # 范围 1.9–2.7 头身
```

**关键修正**：胸部中心在**躯干（肩→腰）的 57%** 处，**不是**白衣 bbox 的 35%。

### 3.4 胸部大小对阴影的影响

| 胸部大小 | 突出度 | 阴影面积 | 阴影上缘位置 |
|---|---|---|---|
| 平（size 0–1） | 小 | **窄带** | 胸部下缘 |
| 中（size 2） | 中 | **中带** | 胸部下缘略上方 |
| 大（size 3–4） | 大 | **大片**（占胸部一半） | **乳头高度**（半球轮廓线） |

**规律**：阴影面积 ∝ 胸部突出度。大胸的阴影上缘上移到乳头高度。

## 四、五官比例（26 张参考图测量）

**测量方法**：肤色检测定位脸部，深色区域检测眼睛/嘴巴，几何估计鼻子位置。戴眼镜角色（如肥宅）通过镜桥分裂检测左右眼。

### 4.1 五官位置规律

| 五官 | 位置（从脸部顶部） | 范围 | 平均 | 说明 |
|---|---|---|---|---|
| **眼睛** | 上 1/3 | 14%–44% | **~30%** | 两眼对称分布 |
| **鼻子** | 中间 | 42%–58% | **~51%** | 眼睛和嘴巴之间 |
| **嘴巴** | 下 1/3 | 69%–75% | **~72%** | 位置最一致 |
| **眼距** | 脸宽比例 | 0%–39% | **~8%** | 两眼间距（戴眼镜者可能更大） |

### 4.2 与传统"三庭"对比

| 传统三庭 | PC-98 实测 | 一致性 |
|---|---|---|
| 上庭（发际→眉）= 33% | 眼睛在 30% | ✅ |
| 中庭（眉→鼻）= 33% | 鼻子在 51% | ✅ |
| 下庭（鼻→下巴）= 33% | 嘴巴在 72%，下巴 100% | ✅ |

**PC-98 风格基本符合传统三庭比例**。

### 4.3 五官定位规则

```
脸部 = 100%
├── 0%    发际线/头顶
├── 30%   眼睛中心 ← 上 1/3
├── 51%   鼻子中心 ← 中间
├── 72%   嘴巴中心 ← 下 1/3
└── 100%  下巴
```

**眼距** = 脸宽 × 8%（两眼中心间距，戴眼镜者可能达 22%）

### 4.4 对阴影的影响

- **眼睛下方**：眼窝阴影（眼球凹陷）
- **鼻子下方**：鼻子投射阴影（鼻底暗）
- **嘴巴下方**：下唇阴影（下唇突出）
- **下巴下方**：下巴投射阴影（颈部暗）

这些阴影都是**人体结构的描绘**，不是皱褶。

## 五、完整人体结构模型（数据驱动）

### 5.1 光源

标准光源：**左上方**（`light_vector("upper-left")`）。

### 5.2 胸部阴影

**形状**：半球背光面（月牙形），不是简单的弧线。

**位置**：胸部右侧（背光侧）。

**大小**：与胸部大小成正比：
- 平胸：窄带，只在胸部下缘
- 大胸：大片，上缘在乳头高度

**上缘**：胸部轮廓弧线（半球轮廓线）。

### 5.3 胸部下方投射阴影

**这是让胸部看起来立体的关键**。

胸部突出 → 遮挡光源 → 在腹部形成投射阴影：

- **位置**：胸部下缘到腰部
- **形状**：大面积暗带
- **宽度**：与胸部大小成正比
- **与胸部阴影的关系**：**连续**，无分界

### 5.4 腰部阴影

**形状**：圆柱背光面（渐变带）。

**位置**：腰部右侧。

**与胸部阴影的关系**：**连续**，连成一体。

### 5.5 中间区（胸部下缘）

知乎文章：
> "中间区大致是一条弧线，更像是**海浪的波纹**"

- 胸部下缘 = 弧线/海浪波纹
- 不是直线，是**曲线**
- 两胸之间**不需要**画阴影（衣服和皮肤之间有空气）

### 5.6 衣袖阴影

**衣袖自身**：圆柱背光面（右侧）。

**衣袖→手臂遮挡阴影**：衣袖遮挡光源，在手臂上方形成投影。

**与躯干阴影的关系**：**连续**。

### 5.7 虚实结合

知乎文章：
> "贴近胸部的阴影是比较**实**的……越使用柔和的笔刷作为过渡，衣服的材质看上去就会越柔软"
> "但是再柔软的基础上也要搭配上比较**硬值边缘**的阴影"
> "缺乏虚实结合那我们整个阴影将会看上去很**糊很脏**"

| 位置 | 虚实 | 边缘 |
|---|---|---|
| 贴近身体（胸部、腰部） | **实** | 硬边缘 |
| 远离身体（腹部、衣袖末端） | **虚** | 柔和过渡 |

**不能全软（糊），也不能全硬（碎）**。

### 5.8 头部与脖子阴影

**头部 = 球体**：

| 属性 | 规则 |
|---|---|
| 背光面 | **右侧月牙形**（与胸部同理） |
| 面积 | 与头部大小成正比 |
| 颜色 | 比肤色**暗一档**，不是深棕色 |
| 形状 | **月牙**，不是一大片 |

**脖子 = 圆柱**：

| 属性 | 规则 |
|---|---|
| 背光面 | **右侧暗带** |
| 与头部关系 | **连续**——头部下缘暗 → 脖子右侧暗 |
| 与身体关系 | **连续**——脖子暗 → 身体暗 |

**头发遮挡阴影**：

| 属性 | 规则 |
|---|---|
| 位置 | 头发下缘到脸部 |
| 形状 | 沿头发轮廓的暗带 |
| 与头部自身阴影的关系 | **叠加**——头发遮挡 + 头部背光面 |

**五官阴影**（§4.4 已述）：
- 眼窝：眼球凹陷 → 眼睛下方暗
- 鼻底：鼻子投射 → 鼻子下方暗
- 下唇：下唇突出 → 下唇下方暗
- 下巴：下巴投射 → 脖子暗

**当前实现的问题**：
- 头部阴影**太大**——覆盖脸部右侧大部分
- 颜色**太深**——接近头发颜色，不像肤色阴影
- 形状**不对**——一大片，不是月牙形

### 5.9 裙子阴影

**裙子 = 覆盖在腿上的薄壳**：

| 层次 | 内容 | 阴影来源 |
|---|---|---|
| **底层** | 腿部圆柱 | **人体结构**——腿部背光面 |
| **表层** | 百褶裙皱褶 | **衣服形状**——皱褶小阴影 |

**底层阴影**（人体结构）：
- 腿部是圆柱 → **右侧连续暗带**
- 从大腿到小腿 → **连续**
- 这是**主要的**阴影

**表层阴影**（衣服皱褶）：
- 百褶裙皱褶 → **细条纹**
- 但**必须服从底层的大方向**（右侧暗）
- 皱褶阴影是**叠加**在底层之上的细节

**当前实现的问题**：
- 只有**表层**（皱褶条纹）
- 缺少**底层**（腿部圆柱背光面）
- 结果：裙子阴影是**一条一条的皱褶**，不是**连续的人体结构**

**正确做法**：
```
底层：腿部圆柱背光面（连续右侧暗带）
  ↓ 叠加
表层：百褶裙皱褶阴影（细条纹，服从底层方向）
```

### 5.10 腿部阴影

**腿部 = 圆柱**：

| 属性 | 规则 |
|---|---|
| 背光面 | **右侧渐变暗带** |
| 形状 | **圆柱曲面**，不是外轮廓描边 |
| 颜色 | 比肤色/袜色**暗一档**，渐变 |

**两腿关系**：

| 光源方向 | 左腿 | 右腿 |
|---|---|---|
| 左上 | 较亮 | **较暗**（背光侧） |
| 正上 | 对称 | 对称 |
| 右上 | **较暗**（背光侧） | 较亮 |

**关键**：两腿都有背光面，但**程度不同**——不是一条腿全暗一条腿全亮。

**与身体的连续性**：
- 腿部阴影与身体阴影**连续**
- 从躯干到腿，是**一体的背光面**

**当前实现的问题**：
- 左腿**太大**——覆盖整个小腿左侧，像"外轮廓描边"
- 右腿**太小**——只有一条细线
- 两腿**不对称**——没有统一的光源逻辑
- 形状**不对**——不是圆柱背光面，是"外轮廓描边"

**正确做法**：
- 左腿：圆柱背光面（右侧暗带，较亮）
- 右腿：圆柱背光面（右侧暗带，较暗）
- 两腿**都有**背光面，但程度不同
- 阴影**渐变**，不是"外轮廓描边"

## 六、遮挡关系

### 6.1 胸部→腹部

胸部突出 → 遮挡光源 → 腹部形成投射阴影。

### 6.2 衣袖→手臂

衣袖覆盖手臂 → 遮挡光源 → 手臂上方形成遮挡阴影。

### 6.3 头发→身体

头发覆盖肩部/胸部 → 遮挡光源 → 身体形成遮挡阴影。

### 6.4 领子→衣身

领子覆盖衣身 → 遮挡光源 → 衣身形成遮挡阴影。

**所有遮挡阴影都与被遮挡部位的自身阴影连续**。

## 七、完整阴影模型

### 7.1 整体结构

```
整个身体右侧 = 一体的连续背光面

胸部背光面（月牙）
    ↓ 连续
胸部下方投射阴影（大面积暗带）
    ↓ 连续
腰部背光面（渐变带）
    ↓ 连续
骨盆背光面（月牙）
    ↓ 连续
手臂背光面（圆柱暗带）
    ↓ 连续
手部背光面（圆柱暗带）
```

### 7.2 虚实分布

```
贴近身体 = 实（硬边缘）
    ↓ 渐变
远离身体 = 虚（柔和过渡）
```

### 7.3 与衣服的关系

```
人体曲面 → 计算明暗场 → 套到衣服 silhouette 内
```

衣服只是**载体**，阴影的**来源**是人体结构。

## 八、与现有管线的差距

### 8.1 当前实现的问题

| 问题 | 现状 | 正确做法 |
|---|---|---|
| 阴影破碎 | 胸部、腰部、衣袖分开画 | **整个身体右侧一体背光面** |
| 胸部定位错误 | 白衣 bbox 的 35%（肩线附近） | **躯干的 57%** |
| 胸部阴影太小 | 小月牙 | **大面积**（与胸部大小成正比） |
| 缺少投射阴影 | 无 | **胸部→腹部投射阴影** |
| 缺少中间区弧线 | 无 | **胸部下缘海浪波纹** |
| 无虚实时渡 | 全硬边缘 | **贴近实、远离虚** |
| 缺少遮挡阴影 | 只有材质接缝 | **胸→腹、衣袖→手臂、头发→身体** |
